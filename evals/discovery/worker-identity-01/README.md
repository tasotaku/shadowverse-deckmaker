# 別々に起動した担当を実行側の識別値で区別する

**前の実利用で見つかった、担当名の重複による評価保存失敗を修正し、関連93検査・型検査・別担当の5ケース点検に合格しました。実AIの確認を開始します。** 前試行は正式改訂1件・正式評価0件のまま保持します。今回の採否は未判定です。

各工程の起動時に一意な担当IDを割り当て、提出時の担当情報をそのIDへ結びます。モデルの申告名と提出した元本文は公開操作記録に残し、評価内容は書き換えません。元の提出ファイルも保持します。

同名を返す場合、申告名が欠ける場合、担当情報を書き換えた正式ファイル、工程違いの提出を検査します。その後、同じ保存入力から改訂20分・評価15分、各1回で実AIの完走を確認します。未提出、失敗、期限停止はそのまま保存します。

[固定条件](protocol.json)と[記録画面](http://127.0.0.1:8765/#experiment/worker-identity-01)に、結果・採否・工程の開始終了を追記します。担当の識別を修正したことと、案の有用性は別に判定します。
