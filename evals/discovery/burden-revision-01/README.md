# 保留案の採用負担を、配分や使い方の変更で減らせるか

探索システムの開発を依頼したユーザーが、方法の成果と所要時間を確認するための報告です。両方式で改訂案を1件ずつ保存しましたが、別担当による評価は2件とも利用上限で途中終了しました。この試行の有用性は未評価、改訂指示の本採用は保留です。同じ案・同じ評価入力で始めた[復旧後の別評価](../burden-review-recovery-01/README.md)を分けて記録しています。

対象は、前の試行で得た「同期疾走ブレード：ユラティオを挟む5枠の別打点」です。別の担当が評価し、手順の成立は支持しましたが、中盤の守りや進化を遅らせる負担があるため、試す価値は追加検討としました。この案と評価を、両方式へ同じ内容で渡しました。

従来版も、直前の不足や評価を読み、カード・使い方・採用配分・前提の変更を求めます。変更版は、その中でも採用負担を減らす配分・使い方を実際に作ることを優先します。元の構築、直前案、変更案を同じ狙いの局面で比べます。採用枚数を減らして引きにくくなった場合など、別の場所へ移った負担も確認します。

各方式は、この検討を1回、上限30分で行いました。案または根拠資料が保存されたら、別担当が上限15分で最新の案を評価する条件でした。両方式とも改訂を提出し、評価へ進みました。資料だけ追加した場合は、案の改訂は0件として記録します。検討を打ち切る十分な根拠が得られたことと、今後試す価値のある案が得られたことは分けて判定します。

評価では、次の5点を確認します。

- システムの公開コマンドで調査・提出・評価・結果確認まで進めたか。
- カードの効果、PP、手札、場、進化権や相手依存について、手順に重大な誤りがないか。
- 実際の疑問が解消したか、根拠により案が変わったか、適切に検討を打ち切れたか。
- 通常の使い方との差、失う役割、核を引かない場合を踏まえて、採用負担に見合う可能性を持つ案が残ったか。
- 未確認を明示し、検索で見つからないだけで独自性を証明したことにしていないか。

40枚完成・20点確定・勝率証明は要求しません。資料数や文章量、改訂件数だけでは改善と数えません。変更版でも試す価値のある案が得られなければ、本採用しません。

機能面では自動テスト118件と型検査が合格しました。公開コマンドの出力を照合し、通常の改訂指示以外の本文・資料・回答形式が同じことを確認しています。初回考案・独立評価・指定資料の引き継ぎの出力も維持しています。これは実用性の証明にはなりません。

既知の1案を再利用する限定的な比較です。前の試行の結果は変更しません。この結果だけで、新しい案をゼロから発見する力や、方法の一般的な優位は判断できません。

実装担当が、改訂時だけ指示を切り替える試作に着手した記録は、9月10日13時44分10秒です。方針検討の開始は未記録です。機能検査から比較開始までの間隔には会話対応も含み、全体の時間を実作業時間とは呼びません。工程の開始・終了日時は[台帳の詳細](http://127.0.0.1:8765/#experiment/burden-revision-01)、固定した入力と時間上限・採否条件は[比較条件](protocol.json)に保存しています。元の評価は中断しました。復旧後の評価と採否理由は別報告へ記録します。


改訂内容の点検では、両方式とも文章の言い換えだけでなく、配分と行動を変更していました。従来版は鳥像を石像へ替えて準備PPを5から2へ減らし、中盤のリテュエルとユラティオを戻しました。変更版は専用のブレードを外して追加枠を5から3へ減らし、T7姉妹からT8の既存打点へつなぎました。前者には終盤札の減量と打点低下、後者には決着の1ターン延期とT8に必要な2枚・8PP・空き2枠が残ります。これは変更内容の確認であり、試す価値の評価ではありません。
