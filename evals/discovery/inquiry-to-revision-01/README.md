# 保存した追加調査を、案の改善へ使えるか

検証を開始しました。前回保存した7資料を通常の改訂と独立評価へ渡します。資料が増えただけでなく、使い方・構成・採用条件や見送り判断が具体的に改善するかを確認します。

公開入口で改訂を1回、別担当の評価を1回行います。開発者がカード答案を渡したり、以前の判定を変更したりはしません。工程の開始・終了は実行監視から自動記録します。

同じ保存案の前後を比べる試行で、同時対照はありません。一般的な発見力や実戦の強さは、この試行だけでは認定しません。未提出・期限停止も結果として保持します。
