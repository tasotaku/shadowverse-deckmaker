# 保存した追加調査を、案の改善へ使えるか

**本採用は保留です。改訂案1件を保存しましたが、15分の期限停止により別評価へ進めませんでした。** 案が変わったことは確認できても、良い変更かは未確認です。

前回の先例調査と別照合の7資料を含む20資料を、通常の改訂入口へ渡しました。カード答案や新しい改訂指示は開発者から追加していません。入力と実装41ファイル、判定条件を開始前に固定し、元案・旧評価を保存したまま改訂と独立評価を各1回行う計画でした。

実施した手順は、入力への7資料の保持確認、公開入口からの改訂実行、提出・保存の再検査、停止結果の回収です。改訂は比較資料1件と正式案1件を追加し、46回の公開操作はすべて成功しました。正式提出後のreportも成功しています。しかし担当プロセスの自然終了を確認できず、実行側が15分で停止したため、別評価は起動されませんでした。根拠はverification.jsonとdevelop/public-operations.json.gzに保存しています。

提出された案では、相方、使う局面、必要PP、進化権を温存する前提が変わりました。先例調査で見つかった広い着想を新発見と扱わず、追加負担と未確認の発生頻度も記述しています。これらは提出内容の観察です。カード手順の正しさや変更の有用性は、独立評価なしに認定しません。

期限停止を、提出済みだからという理由で成功へ変更しません。原案・旧評価・元資料・固定実装が変わっていないことと、今回の正式案の保存条件を再検査し、部分成果を後から評価できる形で保持しました。方式の有用性を認定する条件のうち、独立評価による裏付けが未達なので採用保留です。同じ案の前後比較で同時対照がないという限界も残ります。

次に直す対象は、正式提出を終えた担当から後続工程へ渡す終了処理です。公開入口で担当が提出終了を明示し、実行側が正式保存・固定入力・子プロセスの終了を確認する方式を点検中です。実装・採用はまだです。今回の保存案の別評価は、新しい試行で再開し、今回の停止記録は維持します。
