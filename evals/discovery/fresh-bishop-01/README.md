指定例では、負傷した後攻2ターン目に追加PPを使い、ティコと構成員を置いて、前ターンの耳飾りをアクトします。別評価は手札・PP・場・効果の順序を条件付きで整合としました。ティコを引かない場合に、既存の聖典を能動的に破壊して回復を使う経路もあります。これらは引き込みや相手の行動を保証した手順ではありません。

**試す理由は、遅い札2枠を安い守護へ替え、元から有用な回復を追加の進化へ利用できることです。** 記事が述べる序盤の弱点への配分実験として、別担当は比較試用の価値があるとしました。早期進化を無理に狙って初手を揃える推奨や、全対面での改善ではありません。

一方、別評価は次を留保しました。

- T2では通常案も進化権を使えません。「進化権を使わない」は成立しても、通常案より1個節約した利益にはできません。
- 追加PPをT2で使うと、温存してT3に暗黒次元を置く選択を失います。単体を守る構成員と、全体を処理する暗黒次元の優劣は対面次第です。
