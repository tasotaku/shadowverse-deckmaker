# 評価後の改訂と再評価を一度の実行でつなぐ

既存の改訂と別評価を、元の記録を保ちながら一回のコマンドで実行する入口を作っています。提出や評価が欠けたまま次へ進まないことを検査します。

前の比較では、考案と評価は完了しても、親担当が資料を複製し、旧採否を分離し、正式保存と時刻を回収する処理を個別に用意していました。その実作業をまとめます。新しい発想法の優位を認定する比較ではありません。

既存の通常指示を維持し、保存済みドラゴン案の改訂を20分、別評価を15分で実行します。改訂・評価の各1件と公開reportまで到達したかを確認します。得られた案の試す価値は別に評価し、改善しなければその事実を残します。
