# 相手の返しを受けた後の利益を比較する

相手の40枚構築とカード本文・注記を、保存済みの探索へ追加する入口を実装しました。機能検査52件と型検査に合格し、マゼルとナイフの既知2例で実際に使って評価中です。方法の有用性と本採用は未判定です。

同じ相手の返しを提案と通常構築に当て、利益を得る時点に何が残るかを比較します。相手の札は保存構築にあるだけで、常に引ける・実戦で頻発するとは数えません。相手資料は7月末取得の構築で、現在の環境を代表するとはしていません。

入口は `python -m svdeck.discovery opponents SESSION --deck-id ID` です。`--preview` なら表示だけです。固定DBから合法な40枚、参照される効果と双方の注記を読み、追加資料へ保存します。枚数・クラス・合法性・欠損を検査し、自分側のカード集合と旧評価は維持します。

実評価は各1回・上限10分。前回の期待判断を維持し、元の出題に相手資料1件と比較手順6文だけを追加しました。実際の出題は固定した内容と全文一致しました。個別の見送り理由への回答を待つ間も、この検証を進めています。
