# 不足を別の役割へ引き受けさせて、着想を発展させる

検証中です。最初に未完成の着想を最大3件集め、同じ資料から二つの方法で種を作ります。一方は通常の発展、もう一方は足りない部分を別の着想や既存の役割へ引き受けさせ、変わった条件で小さな効果の使い道を見直します。

エルフの固定資料を使い、共通の収集は5分、各方法の考案は10分、別評価も各10分です。説明や工程の数ではなく、使い方・採用配分が変わり、通常構築との差から試す理由または判断を変える次の一手が残るかを確認します。同じ発展が通常側でも起きれば、追加工程の優位とは扱いません。
