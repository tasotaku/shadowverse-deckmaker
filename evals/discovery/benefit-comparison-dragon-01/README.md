# 利益の比較を細かく指示する方法は、常用を見送る

追加の4段落は常用を見送ります。ビショップでは通常側にもある翌ターンの利益を明示する差がありましたが、別のドラゴン案では、現行側も追加側も事前の4項目を満たしました。説明の範囲は増えたものの、判断が良くなったとは確認できませんでした。

方法は、案の利益を通常構築の各手順へ対応づけ、共通する利益を差し引いてから、残る利益と代償を採否へ結ぶ指示を足すものです。同じ保存案・資料を固定し、現行指示と追加指示で各1回、上限10分で評価しました。ビショップで使った追加文を変えず、元評価や点検報告を担当へ追加せず、指示以外の入力一致を確認しました。

対象は《世界》の提示1枚を顎門の別れへ替え、生成した深淵を捨てて7PP帯の打点へ回す案です。指示の種類を伏せた別点検では、両方とも次を採否の理由に含めていました。

- 通常側も深淵2枚と波揺花で4点を出せるので、相手体力3〜4を案だけの勝利にしない。
- 主比較の7点は相手体力14を倒せず、通常側の補充と手札5枚に対して案の手札は1枚になる。
- 8〜10PPの通常リュミオールの強さは、7PPと別条件で扱う。
- 新規採用1枠でも、深淵の準備・保持と、提示を減らす補充や大型破壊の損失は残る。

追加側は翌ターンの残り手札の使い道まで詳しく比較しましたが、相手の返しや次のドローは未確認です。両方とも「比較して試す理由がある・独自性未確認」という評価でした。採点の上下や文章量を改善には数えていません。

実測は現行側5分48秒、追加側5分10秒、別点検2分13秒でした。元の案・旧評価を保持し、終了後の保存証拠を再検査しています。各1回で、過去に知っている保存案を使った比較です。効果が常にないと断定した結果ではなく、常用へ加える根拠が足りないための見送りです。
