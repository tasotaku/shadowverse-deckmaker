# 利益の比較方法を、打点と補充を交換する別案でも確認する

ビショップでは、追加指示側が通常構築にもある翌ターンの利益まで差し引いて説明できました。同じ指示を、ドラゴンの保存済み案にも使って確認します。指示本文をドラゴン向けに変更しません。

対象は《世界》の提示1枚を顎門の別れへ替え、生成した深淵を捨てて7PP帯の打点へ回す案です。現行指示と追加指示で、同じ案・資料を上限10分で各1回評価します。通常側にもある4点、7点でも勝たない主比較、残る手札と補充、PP帯による使い分けを、採否の理由へ正しく結べるかを見ます。

元の案・旧評価を保持し、評価担当には旧評価を渡しません。過去に知っている別案の試験であり、未知の案に対する精度の証明ではありません。採点を下げること自体は成功としません。結果と採否は未判定です。
