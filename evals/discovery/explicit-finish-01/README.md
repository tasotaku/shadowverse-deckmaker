# 提出を終えたことを明示し、次の工程へ渡す

終了を明示する機能を本体へ反映し、171件の機能検査と型検査が通りました。**実AIの検証は改訂を考える工程が進行中で、運用への採用は未判定です。**

前の試行では、正式提出と報告が済んでも担当が自然終了せず、約4分11秒待って期限停止しました。今回は担当が「提出終了」を明示し、実行側が提出の対応と保存内容を検査して停止させます。停止後にも内容が同じか、担当の処理が残っていないかを確かめてから次の評価へ渡します。通常の自然終了も使え、期限停止や失敗の記録はそのまま残します。

本体で確認した171件は、新規38件と既存133件です。未提出、入力の改変、期限との競合、停止後の不一致などを含み、検査が報告した時間は45.64秒でした。実AIでは保存済みの改訂案とその別評価を使い、改訂15分・続く別評価10分を上限に一度だけ試します。これは終了処理の確認用の既知入力です。デッキの強さや独自性が改善したという結果には数えません。

実装は目安30分を超えました。途中の検査開始から回収まで約54分の空白があり、その検査自身の報告は19.07秒でした。空白の原因や能動作業時間は未確認です。本体反映後の171件の検査とは分けて残しています。条件固定から担当作業の開始までの待ちや、本体確認の記録時点も[工程の台帳](http://127.0.0.1:8765/#experiment/explicit-finish-01)で確認できます。

採用には、実AIが終了を明示し、保存物を保持したまま次の別評価へ進み、その評価も回収できる確認が必要です。現時点では未確認です。システム全体では、終盤の成功例だけでなく、交換札を中盤に引いた場合の損失を確かめる課題も残っています。
