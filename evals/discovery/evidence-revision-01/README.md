# 保存した根拠から案を改訂する

**追加資料を通常の改訂へ渡す検証を始めます。** 前の調査では、進化した守護をそのターンの単体交戦にも使える根拠を保存しました。今回は、それが実際の使い方・手順・配分・比較判断の変更へつながるかを確認します。

既知の案と評価を再利用する1条件の検証です。元の試行は終了済みで、採点を上書きしません。改訂と別評価を各1回、実行時計の上限15分・10分で行います。判断基準は前回と同じ5項目です。[固定条件](protocol.json)に保存しました。

最初に、担当が実行監視と同じ時計で残り時間を確認できるよう起動説明を補います。カード判断の指示・期限・停止処理は維持します。説明の補足は、関連55検査・型検査2ファイル・4工程の実コマンド8確認に合格しました。次に改訂担当を起動します。[確認結果](verification.json)を保存しています。
