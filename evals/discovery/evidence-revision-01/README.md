# 保存した根拠から案を改訂する

**保存した調査は組み合わせと配分の変更につながりましたが、今回の改訂から試す理由のある案は得られませんでした。** 別評価は「さらに作り直す必要あり」です。前案より改善したとは認定せず、この方法全体の採用は保留します。改訂1件・別評価1件を正式保存しました。

## 何を確かめたか

前の調査で、進化した構成員は4/4になり、そのターンに相手フォロワーを攻撃できる根拠を保存しました。これを通常の改訂へ渡すと、説明を足すだけでなく、使い方や採用配分が変わるかを試しました。既知案1件への追試で、方法同士の優劣を比べる実験ではありません。[元案](../fresh-bishop-01/README.md)と[調査](../bishop-rule-inquiry-01/README.md)の結果は書き換えていません。

事前に[同じ5つの判定基準](protocol.json)を固定し、改訂1回・別評価1回、実行時計の上限を15分・10分としました。カード判断の指示は変更せず、担当へ実行側と同じ時計で残り時間を確認する説明だけ補っています。

## 前案から何が変わったか

| 比較点 | 前案 | 今回の改訂 |
|---|---|---|
| 主な組み合わせ | ティコ・構成員・事前に残したアクト札の3枚 | 構成員と刻みし約束の2枚 |
| 主な早期手順 | 後攻2ターン目に追加PPを使い、負傷中に回復して進化守護 | 3ターン目の通常3PPで、負傷中に2回復し4/4へ進化。そのターンに単体処理も行う |
| 通常40枚からの変更 | 暗黒次元1・イニシア1を構成員2へ替える2枠 | ティコ2・耳飾り1・学級1を構成員2・約束2へ替える4枠 |
| 失う役割 | 全体処理や消滅・回復の枚数が減る | 全体処理の枚数は戻るが、反復回復・手札交換・補充と信仰源が減る |
| 別評価 | 限定的に試す理由あり | さらに作り直す必要あり |

例えば相手が通常の3/4なら、今回案は交戦後に4/1守護を残せます。相手が4/4なら相打ちで、守護や生存を条件とする学級の回復は残りません。負傷、札の用意、相手の状態を指定した例であり、毎試合の到達や勝率を示すものではありません。

## 試す理由が残らなかった理由

**比較相手の三叉槍は、出した直後に無料のアクトも使えます。** 1枚3PPで4点と2点、合計6点をそのターンに処理へ使えます。改訂案はこの2点を後の用途として説明し、通常構築が即時にできることを十分に比較していませんでした。別評価でこの見落としが指摘されました。

構成員と約束に増える利益は、主に回復と交戦後の守護です。そのために手札を1枚余分に使い、デッキから補充札や信仰源を減らす理由は、まだ具体的な相手の動きと結びついていません。組み合わせが3枚から2枚になっただけでは、採用負担が軽くなったとは言えません。

既存の回復札に構成員を添える接続は残るため、案の可能性をすべて否定したわけではありません。ただし、未完成の保留案しか残らない場合は有用な出力に数えないという事前の基準に従い、今回は試行推薦0件と記録します。未実戦、20点不足、独自性未確認だけを理由に下げた評価ではありません。

## 実際の検証手順

1. 元案・元評価と、調査担当と照合担当が保存した4資料を固定しました。元のカードDBと資料の識別値も保存しました。
2. 通常の改訂入口を起動しました。担当は追加資料を含む全1005行を公開入口から読み、組み合わせ・ターン・4枠の配分を変更して正式提出しました。
3. 別担当へ改訂案と固定資料を渡しました。旧評価ファイルは渡していません。ただし過去の資料や改訂理由に旧判断の記述が残り得るため、完全に過去判断を伏せた比較実験ではありません。
4. 別担当が指定局面の手順と通常構築との比較を評価し、三叉槍の即時アクトと、回復・守護に払う負担の問題を指摘しました。
5. 提出された案・評価と公開操作48件（失敗0件）を回収しました。元資料とDBの保持を照合し、5基準と工程時刻を記録しました。未提出の代理補完や追加の改訂は行いません。

[提出案](live/develop/proposal.json)と[別評価](live/review/review.json)が詳細の根拠です。調査資料の増加と、試す理由の増加は分けて評価します。

## 採否と次の改善

方法全体は採用保留です。根拠を改訂へ渡す接続は動き、別評価も比較の見落としを検出しました。しかし、改訂するほど良くなる仕組みは示せていません。今回の改訂を前案の上位版として扱いません。

次は、通常構築が同じ開始状態からできる手順を具体化し、提案が増やす利益と負担を改訂前に比較する工程を検討します。単純なPP計算補助は過去に上乗せを示せず採用を見送っています。今回の候補は、相手の状態・使う札・処理後の体力や手札まで含める比較で、同じものの再採用ではありません。問いの選択から調査・改訂までを自動接続する案もありますが、今回の比較不足に直接効くかを先に点検します。
