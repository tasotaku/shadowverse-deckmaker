# 通常構築を同じ開始状態から比較して改訂する

**改訂前に通常構築の手順を具体化する指示を、現行の指示と1回ずつ比べます。** 前の試行では根拠を案へ渡せても、通常構築が同じターンにできる処理を過小に比較しました。今回は、相手の状態・使う札・終了時の体力や手札まで揃える小さな指示で、実際の判断が変わるかを確かめます。

両側に同じ比較元を指定し、追加側だけに比較手順を足します。本体の既定指示は変更せず、隔離した実装で改訂15分・別評価10分を各1回実行します。最新の失敗案・訂正内容・期待するカードや手順は渡しません。元案・元評価と調査資料までの同じ保存版を使います。

同じ5基準で、実行完了、正しさ、根拠による発展、試す理由、未確認の扱いを判定します。表が増えたことや計算が正しいことだけで採用しません。どちらか片方だけ進んだ場合と同程度の場合を[固定条件](protocol.json)に分け、結果後に変えません。関連62検査と型検査を通過し、実入力が指示以外一致することを確認しました。両側の改訂は2026年9月10日22:30（日本時間）に開始しました。[正確な開始時刻](running-observation.json)を保存しています。
