**比較は完了。両方式とも有用性は不合格で、短い複数着想の比較を必須で加える方式の本採用を見送る。** 同じローテーション・エルフの資料で、一案を選んで掘る方法（a）と、最大3件の着想を短く比較して記録してから選ぶ方法（b）を試した。

全6検討回と全6別評価を固定した5項目で採点した。両方式とも工程・指定条件の手順・判断の発展・誠実な説明は範囲付き合格、有用性は不合格。手順の合格は訂正資料まで合わせた範囲で、aの正式本文には古い2PP差が残る。必要札・生存・自然な対戦での到達、実戦の強さは未確認。[原評価](final-evaluation/evaluation.md)、[工程別の時刻と根拠](final-evaluation/evaluation.json)、[採用を見送る理由](method-decision.json)を保存した。

両方式とも3検討回・2正式提出・3別評価。bの考案担当の停止と最終別評価の追加検討という不一致を残し、上限を延長しない。初期の4資料はaで30件、bで29件になったが、資料の増加を成果には数えていない。方式の優越・成功率・未知入力への一般化は示さない。

第2回の評価は、aが手順は条件付き・追加検討・中核の使い方は既出、bが手順は条件付き・追加検討・既出状況は未確認。第3回のaは通常案にも追加PPを使わせる比較で差を1点・1PPに訂正したが、その差が役立つ実局面と到達の根拠を得られなかった。bはベア1枚と現行の中心札を含む公開仮組を確認したが、自案の40枚とは11枚が異なる。防御後の既知手札で攻撃へ戻れず、ヒエンを減らす負担との比較も未解決だった。双方とも資料を追加して理由付き停止とし、正式提出は各2件のまま。時間上限だけを理由に止めたものではない。
