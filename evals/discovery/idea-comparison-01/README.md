# 着想を短く比較する手順の試行1

同じローテーション・エルフの資料を使い、現行の一案を選ぶ進め方（a）と、最大3件の着想を短く比較して記録してから選ぶ進め方（b）を試す。標準の考案・評価指示は変えず、既存の資料追加と提出の公開入口を使う。**両方式とも上限の第3回の調査を完了し、追加資料と理由を残して新しい案の提出を見送った。最後の独立評価を実施中で、5項目の最終採点と方式の採否は未判定。**

第2回の評価は、aが手順は条件付き・追加検討・中核の使い方は既出、bが手順は条件付き・追加検討・既出状況は未確認。第3回のaは通常案にも追加PPを使わせる比較で差を1点・1PPに訂正したが、その差が役立つ実局面と到達の根拠を得られなかった。bはベア1枚と現行の中心札を含む公開仮組を確認したが、自案の40枚とは11枚が異なる。防御後の既知手札で攻撃へ戻れず、ヒエンを減らす負担との比較も未解決だった。双方とも資料を追加して理由付き停止とし、正式提出は各2件のまま。時間上限だけを理由に止めたものではない。

第3回の実測時刻は、aが20:12:19.700994開始、20:21:00調査終了、20:25:27.948996保存終了。bは20:10:39開始、20:29:21.516320調査終了、20:33:27.868816保存終了（2026年9月8日、日本時間）。[aの原記録](a/round-3/generation-archive.json)、[bの原記録](b/round-3/generation-archive.json)、配信時刻や通知を含む[進行記録3](round-3-progress.json)に残す。最後の評価結果が提案担当の停止判断と異なる場合も、上限を延長せず不一致を残す。

初回の独立評価では、aは準備負担と既存の手札整理役との比較、bは同じ手札・盤面・相手の一手全体を揃えた比較が不足とされた。両担当とも形式再試行0で登録でき、各回答と公開reportの全文対応・引用字句を照合した。第2回も評価登録と引用の照合を完了。実際の配信指示と入力はa/bのround-2、配信直前の時計観測と終了目安は [進行記録2](round-2-progress.json) に保存する。

aは「余ったフェアリーを、強化済みレイピアの追加分へ替える」案を提出した。bは補充役と防御役の着想2件を比較し、初めに選んだ補充役の利益・配分が既出と分かったため、防御役を1枠加える案へ切り替えた。防御役の基本機構も既出と明記している。どちらも未確認を残した仮説で、提出や選び直しができたこと自体を有用性の合格にしない。

初回の元資料と操作記録は [aの保存記録](a/round-1/manifest.json) と [bの保存記録](b/round-1/manifest.json)。担当が記録した開始と保存終了は、aが18:51:52〜19:16:40、bが18:51:59〜19:14:45（2026年9月8日、日本時間）。これは保存作業を含む実経過であり、思考時間だけの比較ではない。aの調査終了の実時刻は未記録、bの調査終了記録は19:11:57。工程の配信時刻・終了目安・20分と25分の通知は [進行記録](round-1-progress.json) に保持する。

開始前に [手順と判定条件](protocol.json)、実際の担当指示、初期資料を固定し、[独立点検](protocol-audit-final.md)を行った。採用可能113枚と関連99枚、既知構築4件を含む同一の初期資料を両担当へ渡す。先行の自然試行で作った案や評価・調査は含めない。カードと構築内容は先行試行と同じで、来歴欄source:nullの明示が加わっている。

各方式は初回を含む最大3検討ラウンド。追加資料だけの調査も1ラウンドに数える。案のない終了、停止対継続の不一致、時間上限、形式再試行を保存する。初回の考案は25分を目安に新しい調査を止め、保存・形式修正に5分の猶予を設ける。評価は20分を目安とし、超過や未確認を隠さない。

工程、正確さ、発展、有用な出力、誠実さの5項目と、作業負担を分けて記録する。比較記録の充実や適切な停止だけで有用な出力を得たことにしない。担当差を含む1組であり、勝者・方式の優越・成功率を決める検査ではない。同じクラスを再利用する開発上の比較で、別入力への一般化と実戦の強さは未確認。
