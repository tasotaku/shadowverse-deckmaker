# 評価に残った進化・回復の基本ルールを調べる

**調査の条件を固定しました。** ビショップの別評価に残った一問を、既存の調査と別担当の照合へ渡します。今回の案の強さを再採点する試行ではありません。

## 対象の問い

固定資料で未確認の進化後スタッツ・効果進化直後の攻撃可否・最大体力時の誘発を確認すると、早期守護の実際の処理能力や成立範囲はどれだけ変わるか。

元の[案・評価と入力不足](../fresh-bishop-01/README.md)を保持します。調査は制限15分、別照合は制限10分で各1回。実行側がそれぞれの開始・終了を台帳へ保存します。

## 手順と判定

1. 保存評価の問いを指定し、通常の調査担当を起動します。
2. 出典・観察時刻・根拠と解釈・未確認を資料へ保存し、保存本文を読み直します。
3. 別担当が調査報告と根拠を照合して、自分の報告を正式保存します。
4. 元の案・評価・本体DBの保持、公開操作、問いに答えた範囲を確認し、採否を記録します。

資料の存在だけで問いが解けたとは判定しません。公式で確認できた規則と推論を区別し、分からなかった場合もそのまま記録します。[固定条件](protocol.json)に判定基準と時間上限を保存しています。

## 現在の段階

準備を開始しました。調査と別照合の実測時刻・結果・採否は、終了後に追記します。
