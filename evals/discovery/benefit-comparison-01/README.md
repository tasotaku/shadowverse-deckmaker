# 通常構築の各手順まで利益を対応づけて評価する

追加指示側は、通常構築にもある翌ターンの起爆まで比較に含められました。現行指示側も進化権の交換には触れており、今回の差はこの共通する次手の扱いです。この時点では本採用を保留しました。その後、同じ追加指示で行った[ドラゴンの別案の検証](../benefit-comparison-dragon-01/README.md)では両方が事前4項目を満たし、追加指示の常用を見送っています。

発端は、新しいビショップ案の評価で翌ターンに聖典を起爆できることが試用理由になった一方、通常側にも同じ次手があることを、代償の違いと十分結び付けていなかった点です。同じ案を、現行の評価指示と、各通常手順へ利益を対応づける4段落を足した指示で評価しました。資料と上限10分は共通で各1回。元評価・指摘報告は渡さず、指示以外の入力一致を確認しました。

通常構築は、元の石像・イニシアの配分を保った構築です。指示の種類を伏せた別担当の点検では、追加指示側は事前の4項目を満たし、現行側は3項目を満たして1項目が部分的でした。通常側の一手順も聖典と手札の天書を残し、進化権1個を使って同じ起爆を用意できると明示した点が差です。進化権の交換、相手の返しの未確認、石像の疾走素材などを減らす損失は両方が扱っています。

案の評価は両方とも「比較して試す理由がある・独自性未確認」のままです。採点を下げること自体は改善としません。追加側の手順判定は条件付き、現行側は指定状態以降を支持ですが、対象範囲が違うため、このラベル差も改善件数にはしません。

実測は現行側7分55秒、追加側6分54秒、別点検2分06秒でした。各1回なので速度の優位は認定しません。回収スクリプトは考案用の元資料を除いた評価先で提案を再検査し、一度失敗しました。全履歴のある最終保存先で提案を確認するよう訂正し、両結果を回収しました。AIの再実行はしていません。
