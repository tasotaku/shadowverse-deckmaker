# 先例がある試用候補も明示指定で普及を調査する

先例がある試用候補も、明示指定すれば追加調査できる機能を採用します。保存済みの「イツルギを補充役に使う」候補から、調査と別照合まで実行でき、元案・元評価を保ったまま6件の資料を追加できました。以前は「先例未確認」の評価だけを受け付け、この候補は対象外でした。

追加で得たのは、別筆者が同じ基盤で全体除去・進化権回復・2ドローを検討した記事と、収集された連勝リスト32列中26列でイツルギを採用する限定資料です。後者はカードの採用数で、同じ目的で使った割合や一般利用者の採用率を示しません。同用途の公開説明は確認できても、用途ごとの一般的な普及は未確認です。

検証は、元評価からの拒否を確認し、明示指定の対象だけを追加して機能検査を実施。その後、同じ旧評価から調査と別照合を各1回・上限10分で実行しました。調査9分36秒、別照合7分26秒、実行全体17分03秒です。105件の機能検査と型検査が合格し、別点検でも先例と普及の混同は見つかりませんでした。

採用理由は、先例ありという記録を保ったまま、不足する情報を調べ直せることです。評価後にこの調査を自動で始める対象は、従来どおり先例未確認の試用候補だけです。この17分で新しいデッキや強さの証拠が得られたわけではなく、元案の採否も変更していません。実AIの実行開始後に案内文の出発点を訂正し、その訂正文は機能検査で確認しました。実AIは訂正前の固定版で完了しています。
