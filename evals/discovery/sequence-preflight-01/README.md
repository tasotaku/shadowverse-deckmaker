# 提出前に行動順を点検する方法の比較

**本採用は保留です。変更版は比較の見落としを訂正して1枠の試用候補へ進みましたが、現行側にも自力の訂正があり、指示の効果を切り分けられていません。** この記録は、方法の採否と検証に使った時間を確認するための報告です。システム全体は未完成です。

同じ保存DBから作ったウィッチの初回探索入力で、現行A・変更Bを各一度実行しました。Bにだけ、仮比較を保存してから同じ手札・PP・盤面で行動順を一回点検し、結果を比較と判断へ戻す指示を追加しました。個別のカードや正解は渡していません。変更Bの95件の機能検査・型検査、追加指示以外の実入力一致、両方式の固定実装と保存資料の保持を確認しました。[開始前の固定条件](protocol.json)。

| 比較する点 | 現行A | 変更B |
|---|---|---|
| 提出案 | ララアンセムの終了時生成で、回復後へ打点を集める2枠交換 | ジンジャーの突進をフィーリンの必殺へつなぐ1枠交換 |
| 自分で行った訂正 | 通常側もテトラを先に出せば累積15点となるため、総打点増という説明を撤回 | 通常側も進化を使えば守護を残せるため、利益を限定し仮の2枚採用を1枚へ縮小 |
| 正式な案・別評価 | 各1件 | 各1件 |
| 手順の評価 | 相手行動などの指定条件付き | 指定状態で成立 |
| 試す価値の評価 | 追加検討 | 1枠の比較試用を推薦 |
| 独自性 | 未確認 | 未確認 |

試用推薦は「通常構築と比べ、ユーザーが試す理由がある」という別担当の評価です。勝率や強さの証明ではありません。Bは専用の供給札を増やさず、進化権を使わずに守護を残す選択肢を得る点が評価されました。一方でアラの除去・変身・疾走への転用を1枚分失い、ジンジャー不在や体力1の守護、満場の負担が残ります。どちらの案も用途の先例や現在の普及は調べ終えていません。

Bでは、仮比較の保存が20:05:05、点検結果が20:06:47、正式提出が20:10:22の順でした。点検後も開始状態と不明のドローを維持し、別の手順で得られる利益と進化権の負担を比べています。元の進化権を使わない比較の計算が誤りだったのではなく、通常側にも別の選択肢があると具体化した訂正です。別評価もその手順と配分縮小を支持しました。[保存前後と提出の対応](sequence-evidence.json)。私的な思考の順序までは観測していません。

Aも通常側の別順を比較し、利益を回復の空振りによる3点へ限定しました。ただし、準備中にターンや超進化権の残数を変更した記載があり、同じ開始状態の前後訂正とは認定していません。別評価では、通常側の順序を変えると将来のドローが早まる見落としも残りました。

このため、Bの寄与は再検証する候補として保存し、本体へは取り込みません。推薦0件対1件という差も、カード・局面・難度が違う各一回の結果です。同じ新しい仮比較を両方式へ渡す確認は未着手であり、局所的な点検効果を切り分ける次の検証候補として残します。[別担当の固定基準による評価](independent-outcome.json)、[採否と次の検証](decision.json)。
