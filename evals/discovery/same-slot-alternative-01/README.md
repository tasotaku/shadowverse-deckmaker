# 同じ採用枠を争う代案を比較へ戻す案内

**9月13日09:19:18（日本時間）から、現行と追加版の両方で改訂中です。案内一文以外の実入力は一致しています。方法の効果と採否は未判定です。**

## 何を確かめるか

前の[検索入口の比較](../live-query-discovery-01/README.md)では、有力な代案が記事と検索結果にあっても提案担当の比較から抜け、別評価で初めて比較へ戻りました。そこで、同じ採用枠に入る代案も比べ、その差を採用枚数や使い方へ反映する短い案内を加えます。

例えば、特別な組合せのために通常札を1枚減らすなら、その1枠を別の既知候補に替えた場合とも、同じ手札・盤面から比べます。具体的にどの札を使うかは探索担当が資料から選び、開発者は答えを指定しません。

追加する案内は次の一文です。

> 資料内に同じ不足を満たす有力な代案がある場合は、同じ変更枠・共通構築・開始状態からその代案も1件比較し、差を採用配分・用途・枝の継続判断へ戻してください。

「採用配分」は採用枚数や交換枠、「枝の継続判断」は同じ着想を続けるか別の着想へ移るかの判断です。追加指示は本体へ採用せず、分けた実装で検証します。

## 検証の手順と現在地

1. 開始前に、比較条件・成功と数えるもの・時間上限を固定しました。
2. 前の試験の検索入口あり側が提出した案を、提出終了時点の保存一覧から復元しました。全30ファイルの一致、正式案1件・評価0件・資料25件を確認。後で作られた別評価の入力は除外しました。新しい初見入力の探索ではなく、同じ保存案からの改訂試験です。
3. 考案指示へ一文だけ加える実装を試作。既存の関連122検査と型検査が成功し、公開入口から実際の入力を読んでも、追加文とその識別値以外が変わらないことを確認しました。別評価・調査引き継ぎの入力は完全一致しました。
4. 両方式を一度ずつ開始し、実際に渡った指示・資料を照合しました。改訂は15分以内、続く別担当の評価は10分以内です。提出済み内容を確認してから次工程へ渡します。追加の自動改訂や時間切れ後のやり直しはしません。
5. **現在は両方式の改訂中です。** 正式案と別評価の回収後、比較を提案担当が見つけたか、評価者が後で補ったかも分けて効果を判定します。

## 結果と採否の判断

実装と入力の確認は通りましたが、手法の有用性は未判定です。比較欄を埋めることや弱い旧案を落とすことだけでは採用しません。比較が実際に使い方・採用枚数・候補の変更へつながり、通常構築と比べて試す理由が残ることを主成果にします。

両方式が同じ比較を自力で補えば、追加指示の上乗せとは数えません。各一度の差だけで一般的な効果を断定せず、指定状態の手順成立、試す価値、独自性を別々に判断します。この旧案にだけ有効な可能性も残します。有用性が確認できなければ本体への追加を保留します。
