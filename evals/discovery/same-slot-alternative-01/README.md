# 同じ採用枠を争う代案を比較へ戻す案内

**比較方法を固定し、限定した試作に進みます。まだ比較AIは起動しておらず、効果と採否は未判定です。**

前の検索入口の比較では、有力な代案が検索結果にあっても考案担当の比較から抜け、別評価で初めて比較へ戻りました。現行にも通常構築との比較指示はあるため、検索機能は増やさず、同じ変更枠に置ける既知代案まで比較範囲を広げる短い案内を隔離して試します。

同じ保存済みの仮比較から、現行と追加版を改訂15分・別評価10分ずつ各一度比較します。後の別評価の答えや具体カード名は担当へ与えません。代案を書けたことや案の棄却だけで採用せず、用途・配分の変更と試す理由へつながったかを評価します。

[開始前の条件](protocol.json)。新しい初見入力の試験ではなく、保存した仮比較からの改訂試験です。
