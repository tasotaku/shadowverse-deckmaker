# 試す前に必要な確認の分け方を変える

デッキ探索システムが案を評価する際の指示を変え、利用者本人の「実際に組んで試す候補にするか」という判断に合うかを調べた開発報告です。

**本人判断への一致は0件から1件へ変わりましたが、見送ったナイフ案は今回も試用候補になりました。補足の本採用は保留しました。評価AIへの信頼とシステム全体の完成は、引き続き未確認です。**

| 例 | 本人の期待判断 | 従来の指示 | 補足した指示 |
|---|---|---|---|
| マゼルの前半と後半の役割分担 | 構想段階で試用候補 | 追加検討 | 試用候補 |
| 当該ナイフ2枠交換案 | 見送り | 試用候補 | 試用候補 |

マゼルは、序盤を攻撃と手札消費へ寄せ、後半の補充をマゼルへ任せる構想です。ナイフは、ベルゼバブ3→2枚・ランサー1→0枚・リオナ0→2枚へ替え、潜伏させたナイフとリオナが翌ターンに攻撃する案です。

2例＝一致1＋不一致1です。開発に使った既知の2例を各1回評価した結果であり、未知案への精度や、補足だけが変化の原因だという再現性は確認していません。マゼルの構想を自然な探索で発見した実績でもありません。

マゼルでは、後半の補充を別の山札へ任せ、元の構築を序盤へ寄せる利益を、具体的な配分を試す理由として扱いました。4PP・進化権・補充を使えるまでの時間差・元の後続札を失う負担は残しています。前回求めた具体的な配分差を、今回は試す中で測る項目へ移しました。

ナイフでは、条件付きで1ターン早める経路、通常の決着札を引けないときの別用途、2枠の低コスト化を試す利益としました。潜伏しないリオナの生存、原本ナイフの生存と攻撃、人形・進化権の温存、失う通常札も読んだうえで、頻度と損失は試用で測ると判断しています。説明の充実だけから推薦したわけではありません。この重み付けと本人判断の不一致が残っています。

## 試した変更と手順

1. 前回の最終入力と期待判断を再利用しました。出題用コピーだけで当該案の過去の採否・実績を伏せた状態も維持しています。詳細は[前回の入力準備](../reviewer-utility-01/README.md)にあります。
2. 通常の評価指示へ[5文](review-addition.txt)を加えました。得る機会・失う用途・共有する準備・追加の資源予約と相手依存を照合し、残る疑問が「試す理由の不足」か「試用で測る項目」かを分ける補足です。カード名や固定した正解は入れていません。
3. 保存・読出し・不正入力の拒否など57件と型検査に合格しました。実行時の出題も事前の内容と全文一致し、前回からの差は評価指示だけでした。
4. 隔離した実装から各1回、上限10分で正式評価を実行しました。追加改訂0件、正式評価2件、再試行0回です。元の入力・実装の保持、正式保存、提出後の終了と停止を再照合して回収しました。
5. 別担当の照合では、本人判断への一致は1/2でした。利益と負担・成立条件・判断を適用する範囲の説明を各例3項目ずつ確認し、6/6項目に記述がありました。カード効果に基づくPP・手札・場・進化権・打点の主要手順を照合し、重大な誤りは確認範囲で0でした。理由が揃うことと、採否が本人に合うことは分けています。全544カードの全欄の精読や実対戦はしていません。
