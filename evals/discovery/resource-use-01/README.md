# 生んだ資源を別の使い道へつなぎ、元案と比べる

**条件を固定し、変更版の実装を準備中です。本採用・有用性は未判定です。**

同じ案・評価・調査資料から、現行の改訂と、既存の手順や先例にない要求へ一枝だけ検索を戻す改訂を比べます。元案も残して選び、個別のカードや要求の答えは指定しません。順番や枚数だけを変えた結果を発見力の改善とは数えません。

両方式とも改訂15分・別評価10分を各一度。過去案を含む開発用の比較で、新規入力への転用前に本体へ採用しません。
