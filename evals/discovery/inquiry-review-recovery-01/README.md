# 保存済みの改訂案を、作り直さず別評価する

**別評価は約7分20秒で完了しました。追加調査を使う方法の本採用は、引き続き保留です。** 改訂の一部の変更と指定局面の手順は支持されましたが、比較試用を勧める根拠には届きませんでした。

元の試行では改訂2の正式案と比較資料を保存した後に15分で期限停止し、別評価が未実施でした。今回、その保存案の提出条件を再検査し、既存の別評価だけを再開する入口から別担当を1回だけ起動しました。案は作り直さず、旧採点を隔離した評価用資料を渡しています。元の案・旧評価・元入力・実装が変わらないことと、新しい正式評価1件を確認し、履歴付きの保存先へ残しました。

別評価は、進化権と特定の相方を序盤から温存しない変更、通常の決着札が手札にあっても当ターンの決着へ届かない指定例を支持しました。一方、主比較は8PPから10PP、相手体力10から4、守護1体から2体へ変わっており、元の局面で性能が改善したわけではないと指摘しています。交換元の札が担っていた中盤の展開・処理を失い、その交換元自身が新しい相方でもあるため、採用負担は解決していません。

採用保留の理由は、資料を読めたことと案の一部を変えたことは確認できても、通常運用で失う役割を補える有用な案への改善を示せなかったためです。別評価は手順の成立を支持し、価値は追加検討としています。原記録の独自性分類はknownですが、中核の着想の先例を指す説明で、一般的普及率は未確認と明記されています。この区別を保持し、先例があることを一般に普及していることへ読み替えません。

次の比較上の課題は、成功しやすい終盤の指定局面に加え、交換札を中盤に引いて使う局面や、通常の別手札を使った場合の損失も同じ条件で比べることです。条件の違いで勝てる例を作れたことと、採用価値が上がったことを分けます。この改善指示は今回の担当へ後付けしていません。

同じ保存案を使う前後の観察で同時対照はなく、一般的な発見力・独自性・実戦の強さ・システム全体の完成は認定しません。今回の別評価も外部Webの再取得はせず、保存された抜粋と出典の範囲で判断しています。新しい提出終了方式の実装・検査とは別の試行です。
