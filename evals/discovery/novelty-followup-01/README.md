# 比較試用の後に、使い方の先例と普及を調べる

**任意の調査接続として採用します。** 保存済み案から、問い番号を手動選択せずに調査と別担当の出典照合へ進み、7件の追加資料を残せました。近い使い方の先例と、まだ判断できない普及の範囲を具体化しています。案の独自性・実戦の強さや、システム全体の完成を認定した検証ではありません。

## 何を変えたか

これまでは、正式評価が「比較試用・独自性未確認」で終わると、残った問いのどれを調査へ渡すかを人が選んでいました。今回の入口は、最新の正式案に対応する評価がその条件を満たす場合に、使い方の先例と普及という固定の調査目的を設定します。細かな問いの文章をキーワードで選別しません。

保存済み案では `discovery_inquiry --novelty` から実行できます。`discovery_cycle` では追加の調査・照合予算を明示した場合だけ、最終評価後にこの2工程を一度接続します。条件外では通常どおり終了します。元の案・評価を保持し、調査結果は追加資料として保存します。

## 実際に行った手順

1. 対象条件・停止条件・採用基準を開始前のprotocol.jsonに固定しました。検索で見つかることも、見つからないことも合格条件にはしていません。
2. 条件判定と接続を実装しました。元の正式案と評価を保存入口で再検査し、旧資料・実装を保持します。対象案に評価が複数ある場合は、この任意入口では拒否します。従来の問い番号指定は維持しました。
3. 合成データで、条件外・古い案・不正な保存物・不正予算の拒否、失敗時の停止、考案→評価→調査→別照合の接続を確認しました。関連159件と型検査を通過しています。独立コード点検の後に追加した正式保存の再検査2行は、破損拒否を含む機能検査と型検査で確認しました。
4. 直前のcycle-runner-01が保存したエルフの正式案1件・別評価1件を入力にしました。rootはカード答案・先例の答え・問い番号を追加していません。実装41ファイルと元の入力を固定しました。
5. 実AIが公開Webを調べ、検索語と取得範囲、出典の抜粋と解釈、結論、時計を4資料として保存しました。正式な添付と保存後の全文再読を確認し、別担当へ自動で渡しました。
6. 別担当が主要な出典を再取得して照合し、根拠・結論・時計を3資料として追加しました。計7資料です。両工程とも正常終了し、公開操作のエラーは0件でした。
7. 元の案・評価が保たれた出力を保存し、採用理由と残る限界をこの報告と進捗画面へ記録しました。

初回の機能検査では5件が失敗しました。試用判定に必要な説明と合成の照合資料が不足し、合成実行側が固定実装へPythonのキャッシュを生成していました。合成データ・実行側を直し、製品の採点条件や保存条件は緩めていません。最後は新26件を再検査し、直前に合格した関連133件と合わせ159件を確認しました。

## 得られた結果

対象は「導きの船頭1枚を森羽子板の匠へ替え、既存のシトラスを後半の即時打点にも使う」という保存済み案です。出典を調べて、次の区別を残せました。

| 確認したいこと | 調査と別照合の結果 |

| 一般に広まっているか | 判断できません。攻略記事への掲載、個人の投稿や紹介件数を、用途別の採用率へ変換できませんでした。 |

根拠は[MOPXの記事](https://note.com/honest_phlox9670/n/n23525979685d)と[hanhansの記事](https://hanhans.hatenablog.com/entry/2025/12/31/014119)などです。前者は旧環境の個人の使用報告、後者は組み合わせの提案という違いも保持しています。後にカードを入れ替えた後の到達成績を、匠入り構築の実績にはしていません。

別照合では、広い終盤打点役の先例は既にあること、細かな条件が一致しないだけでは新規性の根拠にならないことを明記しました。妖精登場の仕組みとの対応にはカード能力も合わせた解釈が含まれ、個人記事が今回の具体的な操作順を直接報告したわけではありません。

## 採用する理由と残る限界

手動で問い番号を選ばずに、正式な入力から調査・別照合・履歴付き保存まで進めました。元の固定資料だけでは分からなかった先例を出典本文に照らして具体化し、一般的普及は未確認と区別できたため、任意の調査接続として採用します。

実AIで確認したのは**保存済み案からの後続2工程**です。考案から全工程をつなぐ実AI検証ではなく、その接続は合成の別プロセスで確認した範囲です。資料保存を根拠に元の評価を変更しておらず、正式案・正式評価の追加はともに0件です。

出典保存は短い抜粋・要約・検索操作の記録で、全検索応答や全ページ本文の保存版ではありません。全候補・除外理由・取得失敗まで別担当が再確認したわけでもありません。参考40枚と掲載フォーマットは再確認しましたが、公式の最新合法性や実機手順の再認定ではありません。原投稿、原動画の操作、用途別の採用母集団、実戦頻度・勝率は未確認です。

この結果は、案の独自性や強さの証明ではありません。根拠を得た後に次の発想・改訂の質が上がるか、新しい入力でも望む種へ進めるかは、システム全体に残る課題です。
