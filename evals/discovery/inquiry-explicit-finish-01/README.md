# 調査報告を保存した時点で終了を明示する

明示終了の機能は実装検査に合格しましたが、通常の実調査での採用判断は保留です。実AIは10分で出典4件と草稿を作ったものの、草稿の公開提出前に期限で止まりました。終了命令を付けるだけでは、報告の提出時間を確保できませんでした。

案の考案・評価で使っている「保存が終わったら終了を要求する」処理を、調査・別照合にも任意で使えるようにしました。提出物、公開操作、元の入力、終了前後の同一性を確認し、期限切れや未提出を成功にはしません。未指定の挙動は変えていません。

実装は268検査と型検査に合格しました。実調査はドラゴン案に残る、先行記事に具体的な締め方と1枠交換の記載があるかという問いで試しました。公開操作の失敗は0件で、監視は600秒で停止を確認しています。草稿の最終更新は期限約12秒前で、報告の添付・全文再読・最終報告・終了要求は未実施でした。出典収集と報告作成の時間配分が問題の候補ですが、それぞれに費やした実作業時間は分かりません。

別用途の共通着想収集では、この終了経路を使って4分46秒で資料の提出から終了後の再検査まで完了しました。この結果は[着想の発展方法の検証](../fragment-handoff-01/README.md)に分けて保存しています。通常の外部調査と別照合を一貫して完了できる証明には広げません。

未提出草稿は草稿のまま保持しました。次は残り3分で新しい取得を打ち切り、未確認を含む報告の提出へ移る小さな変更を試します。元の期限切れは維持し、保存済み出典と草稿を引き継いで同じ取得を重複させません。
