# 探索システムの実利用評価

方式の本採用と開発完了は未確認。評価に使った入力は、以後の開発用事例として扱う。
個別の正解と採点結果はここに置き、探索担当へ渡す設計原則へ混ぜない。

| 検査 | 観測結果 | この検査では示していないこと |
|---|---|---|
| [仮想カードの因果関係](role-chain/README.md) | 固定条件の正例と一条件変更の対照を区別、2/2件PASS | 初版で解けており、複数改訂の有用性・実カードの発見力・実戦の強さは未確認 |
| [既知の案の再評価](known-candidate-review/README.md) | 固定した採否との一致1/2件でFAIL。ナイフはdrop、イマリ17枚型はdevelop | 初回の未評価案として渡しており、同じ枝を何度も保留する挙動までは検査していない |
| [資料だけを補った再評価](source-only-review/README.md) | イマリはdevelopのまま。追加3資料はすべて引用された | 資料補充だけでは採否が変わらなかった1観測。旧40枚と履歴は依然欠けており、原因は単独確定できない |
| [実リストの交換枚数](deck-comparison/README.md) | 種類別の純増減0枚と、実際の交換2枚を区別。不完全な比較元は拒否 | 比較した構築の強さや、改訂したAIの価値判断は評価していない |
| [改訂と実施結果の別評価](history-review/README.md) | 改善したaは残し、確認済みの問いを言い換えたbは限定して打切り。固定条件2/2件PASS | 入力担当が作った改訂を読む検査。自然な探索で改訂を思いつく力は未確認 |

| [主役を指定しない自然試行1](natural-trial-01/README.md) | 初回提出と追加比較を実施。提案担当の停止に対し評価2はdevelopで、残盤面と翌ターンを追加確認中 | 停止の妥当性・有用な種の獲得・最終採点は未確認 |

イマリの入力には、比較元の完全な旧40枚と具体的な序盤の使用者経験が欠けていた。
さらに、提出はrevision1・parent0で、過去の案や実施済みの比較結果を含まなかった。
元のFAILは保持するが、初回の検討価値について現在の指示に沿った判断だった可能性もある。
これだけを根拠に「次の調査に残す判断が誤り」と確定しない。
根拠と次の検査の範囲は [独立した評価条件の点検](continuation-audit.md) に記録している。

保存済みの事実・経験だけを補った再評価と、変更履歴・実施結果を渡す検査を行った。
比較元の完全な旧リストは復元できておらず、現在のページや型別の差から作り足していない。
次は主役を指定しない実カードの入力で、公開入口から自然に着想・調査・改訂を進める試行を行う。
用意した案を読めた結果と、役に立つ種へ到達できた結果は分けて記録する。
