# 実験の採点を除いた入力で新しい種を探索する

ビショップの保存DB版で、新しい種の考案と別評価を実行中です。特定カードや正解を指定せず、既知構築の役割・採用配分を変える案を探索します。結果と採否は未判定です。

通常のカード本文・両側の注記・ゲームルールを保持し、実験の採点履歴を原則から除いた新規入力を使います。相手の保存構築1件も添付しました。これは現在の環境を代表する資料とはしていません。

考案は15分、別評価は10分を上限に各1回。正式保存後に、役割や配分の変更、通常構築との差、成立条件、失う用途と残問を照合します。比較対照なしの1回で、入力修正の因果効果や一般的な発見力は認定しません。
