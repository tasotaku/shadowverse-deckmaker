# 実験の採点を除いた入力で新しい種を探索する

ビショップの保存DB版から1案と別評価を得て、先例調査の別照合まで終えました。石像2枚・イニシア1枚を減らし、条規の構成員2枚・ティコ1枚を増やす配分です。元の別評価は条件付きの試用候補ですが、通常構築との利益比較に不足があり、独自性も未確認です。この1回を根拠とする探索方法の本採用は保留します。

AIに渡す設計原則の文章から、過去の実験結果や正解として扱った評価の記述を除きました。通常のカード本文・主役と相方の注記・ゲームルールは保持しています。相手の保存構築1件も添付しました。これは現在の環境を代表する資料とはしていません。

特定カードや正解を指定せず、考案15分・別評価10分を上限に各1回実行しました。実測は考案13分44秒、別評価7分52秒です。さらに別担当が2分15秒で、枚数・主要手順・比較上の利益を照合しました。40枚を保ち、アミュレットは26枚から24枚になります。

案の狙いは、ティコの回復で構成員を進化させ、中盤の処理と守護を担わせながら、聖典を先に置き、翌ターンの起爆用に天書を残すことです。ただし、通常構築にも聖典と天書を残す手順があり、そこでは進化権を1つ使います。起爆できることだけを固有の利益にはできません。進化権を残す利益と、通常側の追加回復・石像などとの交換を、相手の返し後まで揃えて比較する必要があります。元評価は保持し、この不足を追加記録しました。

外部調査では、回復で構成員を進化させて守護・盤面交換に使う公開提案を確認しました。ただし、ティコのアクト回復を起動に使う実使用例や、石像2枠を守護へ回す配分の先例・一般的普及は確認できませんでした。見つからないことを独自性の証明にはしません。別照合は中心結論を支持しつつ、2件の更新日表示が再現しない点と、短い保存抜粋だけでは要約を確かめ切れない箇所を指摘し、周辺本文と40枚表の確認を追加しました。

先例調査は600秒で期限停止し、その後に予定していた別照合は未実施となりました。報告・根拠・全文再読・最終の保存内容確認は期限内に済んでいたため、保存を再検査して回収し、別照合だけを再開しました。再開した別照合は7分39秒、追加資料3件で完了しました。元の期限停止は保持し、調査の再実行はしていません。

また、最初の案の再検査では、実行処理が次の評価資料を完了済みの考案先へ追加したため、一度失敗しました。元ファイルの変更はなく、終了時点の別コピーで再検査して回収しています。この生成順は[保存先の分離](../finished-session-stability-01/README.md)で修正しました。

保留理由は、比較対照のない1回では入力修正の効果を示せず、得た案にも比較と独自性の未解決事項が残るためです。保存資料は現在の環境を代表せず、成立する手札・局面に到達する頻度や実戦の強さも未検証です。次の改善として、[通常側にもある利益を差し引く評価方法](../benefit-comparison-01/README.md)の比較と別案への転用を進めています。
