# 保存済みの調査を、別の担当が提案へまとめる

**正式案1件の提出と独立評価まで完了しました。試行推薦は0件で、この探索方法の本採用は保留です。** 保存済みの調査を提出へつなぐ工程は動きましたが、今回の案では構築を変えるだけの理由を示せませんでした。開発全体は継続中です。

提案は、フェイスドラゴンのキャリーワイバーン2枠を大遊戯世界2枠に替え、既存の1PP行動に遅れて発動する補充を重ねるものです。独立評価は「手順は条件付きで整合／追加検討／独自性は未確認」。追加検討は実際に試す推薦とは区別します。小さい利益や未対戦だけを理由に却下したわけでもありません。

前の2回は調査が進んでも提案ファイルが作られず、正式案0件でした。今回は、保存済みの調査を指定して、提案へまとめる担当を分ける入口を追加しました。担当は報告と回答形式を読み、作業用の下書きを先に保存し、必要なカード本文・注記・不足を確認して既存の提出・報告機能へ進みます。通常の探索指示、元資料、提出検査、独立評価の基準は維持しました。下書きを保存する機能自体は既にあったため、保存の仕組みは増やしていません。

検証は次の順で行いました。

1. ドラゴン／ローテーションの固定入力と14資料を、正式案0件で終了済みの調査からコピー。元の19ファイルを照合し、専用の指示を持つ入力版を1つ追加しました。過去試行の結果は変更していません。
2. 機能検査118件と型検査に合格。通常の探索指示が以前と完全一致し、指定資料の全文を読み出せることを確認しました。
3. 実AIが約1分40秒で最初の下書きを保存。公開操作28回（ヘルプを含む）のうち、同じカードを役割欄へ重複指定した提出が1回拒否されました。担当が修正し、約13分56秒で正常終了。正式案1件と追加資料1件を保持し、提出した全項目を読み戻して照合しました。
4. 別のAIが15資料と正式案を評価。過去の正式評価は渡していません。公開操作17回、失敗0回で約12分58秒後に正常終了し、正式評価1件を保存しました。評価担当へ渡した19ファイルも不変です。

独立評価では、指定状態のPP・手札・盤面・進化権の計算は整合しました。ただし相手盤面、世界の残存、盗人の破壊による回収などの条件があります。複数の分岐を都合よく合算せず、世界の補充が発動するまでの待ち時間を縮める手順と無頼漢を使う手順は分けてあります。

価値の不足は比較で具体化しました。提示された5ターン目の「盗人→キミカ→捨て札」は、世界を採用しない基準側でも実行できます。世界側は手札が1枚多く残りますが、その増分で初めて可能になる必要な攻撃や手札交換は示せていません。一方、キャリーを抜くと盤面・手札への強化を失います。既存の補充を使っても攻撃札が足りない局面と、世界で得た札を期限内に使えるPPを特定することが次の判断材料です。

また、既に引用していた[coolyu氏のフェイスドラゴン考察](https://note.com/coolyu338867/n/n06ea17479a38)には、早い決着と既存の手札回収を理由に世界を不採用とする説明がありました。元の調査要約はこの反対論を十分残していませんでした。これはその人の構築観で、別構築の余地も認めており、一般的な不採用の証明にはなりません。それでも、同じ攻撃基盤からの2枠交換を考える際に、答えるべき論点が要約から抜けたという問題です。
