# 追加調査を採用判断へ戻す比較

**方法の採用判断は保留です。追加調査は主張の訂正に使えましたが、実際に組んで試す理由のある独自な着想へ到達した根拠や、方法の優位は得られませんでした。** 評価で残った疑問に必要な調査を追加し、その資料を次の改訂担当へ渡す既存機能は維持します。

両方式とも正式な改訂と別評価を1件ずつ完了しました。別評価の試用推薦は0件ずつです。ただし、評価AIが良い案と悪い案を見分ける信頼性も未解決で、この判定を独立した正解とは扱いません。システム全体も未完成です。

追加調査ありのBは、後のターンに残る進化権を使う案について、途中の生存・手札保持が未確認だと受け取り、採用理由から外しました。比較する場面を変更し、即時の除去・補充と守護を残すことの交換へ絞りました。元の場面で利益が増えた証明ではありません。追加調査なしのAも、進化権を残す案を見送り、処理後に守護を戻す別用途と配分へ変更できています。

Bには取り落としがありました。通常の構築で「大佐を進化・攻撃させず、ビバティーで小型を処理して深淵で補充する」選択肢を改訂案から落とし、別評価が戻しました。この選択肢は旧資料にも追加資料にもあり、担当への公開読出しの成功応答にも含まれていました。情報が無かったのでなく、比較の変更時に保持できなかった観測です。相手の大型を残す分岐なので、案と同じ全処理ができるとは扱いません。

採用を保留する理由は、資料数や説明が増えても採用負担に見合う理由がまだ示されず、資料なしの側でも用途変更ができたためです。1入力・各1回なので、差の全てを資料の効果に帰属させません。通常側の選択肢を改訂時に維持・変更・不適用へ対応づける案は残しましたが、効果未検証で本体へ追加していません。

後続の[評価AIを裏づける既存検証の点検](http://127.0.0.1:8765/#experiment/reviewer-evidence-01)では、手順の意味と採用価値の識別を分け、正解の出所を確認しました。未知の案に組んで試す価値があるかを見分ける信頼性は、点検した範囲では未確認です。具体的な新しい評価方法や基準はまだ決めていません。

## 手法と検証手順

1. 同じ元案・旧評価・カード入力・指示を固定。Aは27資料、Bは調査・照合7資料と未完了の来歴1資料を加えた35資料です。Bの元調査・照合は最後の追加保存後の確認不足で失敗しており、その事実を資料として渡しました。
2. 検査済みの同じ実装を両方式へ固定し、実際の入力が追加8資料とその派生一覧以外で一致することを照合しました。モデル設定は指定していません。親はカード答案や有利な場面を追加していません。
3. 公開入口で改訂15分・別評価10分を各1回。別評価は別担当が行い、旧評価ファイルは渡していません。ただし追加資料内の過去判断まで伏せた検査ではありません。
4. 正式提出・保存後確認・明示終了・停止・固定入力を再照合し、原本を保持した別の保存先へ回収しました。各方式は過去の改訂3件・評価2件を引き継ぎ、今回それぞれ1件ずつ追加したため、保存全体では改訂4件・評価3件です。Aの改訂中に採用札の指定を1件拒否し、その後の訂正と正式提出も残しました。
5. 方法を別担当が照合し、公開読出しにあった通常側の選択肢の保持漏れと、資料を判断へ戻せた範囲を確認しました。採点の文言の違いだけでBの手順がAより劣るとは判定していません。
