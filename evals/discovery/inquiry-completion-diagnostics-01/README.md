# 提出確認のどこで止まったかを分かるようにする

**別の作業場所で実装・検査中です。本体への採用は未判定です。**

直前の調査は、添付と全文再読は済んでいたのに、最後の追加保存後の報告確認がなく止まりました。現在の表示は3種類の不足を同じ文で知らせるため、どの操作が必要か分かりません。

失敗理由を区別し、全ての追加保存の後に報告確認を行う手順を明記します。受理条件や保存形式は維持し、最後の追加後に確認していない実行を成功にしません。これは診断補助で、デッキ発見力の改善ではありません。

検査は、添付不足・全文再読不足・古い報告確認の拒否と、追加保存後の確認の受理、公開入口での表示を扱います。実装と検査の開始・終了は担当の実時計を回収して追記します。台帳登録時刻を作業開始時刻に置き換えません。
