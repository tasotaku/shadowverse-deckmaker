# 探索に渡す判断原則と実験の採点履歴を分ける

**通常の新規探索へ実験の正解・採点履歴が混ざる不具合を修正し、入力の修正として採用しました。** 判定するAIが賢くなったという結果ではありません。修正した入力での新しい考案・別評価は、[ビショップの探索](../clean-input-discovery-01/README.md)として実行中です。

以前は設計文書の章全体を取り込んだため、マゼルを正例に使うという実験の指定や「一致0・不一致2」なども、通常の判断原則に入っていました。本文を消さず、実験履歴37範囲を明示し、探索開始時の取り込みから外しました。境界の閉じ忘れ・重複・不正な書式では新規開始を拒否します。旧入力や旧採点は書き換えません。

公開入口で新しく資料を作り、対象カード212枚・注記16件・ルール・保存構築が前と同じであることを確認しました。点検した採点文言17件は含まれず、確定した運用原則13文は残っています。マゼルの役割変更への本人評価と当該ナイフ案の見送りは、各カードを採用できるクラス・形式の別入力でも、3枚のカード注記へ保持されています。通常のゲーム知識を消す修正ではなく、過去の実験の答えを伏せて出題する試験とは別です。

機能検査67件（7.11秒）と型検査は合格。別担当の限定確認でも、必要な比較原則の欠落は見つかりませんでした。指定されていない履歴の自動発見や、未知の種の質の改善までは確認していません。

工程の時刻は日本時間です。別担当の点検は 09/13 21:44:08〜09/13 22:19:39（2131.0秒）、修正は 09/13 22:23:10〜09/13 22:32:14（543.9秒）でした。点検は短いコマンドの実行時間と大きく違い、原因未解明の間隔を含みます。重複した工程と全体の期間は[工程記録](http://127.0.0.1:8765/#experiment/principles-separation-01)に保存しています。
