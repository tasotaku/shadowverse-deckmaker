# 既知案への変更後に残った問いを、比較へ移す

**開始前の条件を固定し、追加指示を限定して試作します。比較AIはまだ起動しておらず、効果と採否は未判定です。**

前の試験では両方式とも同じ既知の代案へ移りましたが、別の時点で使う場合や失う役割について問いが残りました。今回はその既存の問いを一件選び、問いの保存だけで終わらず、通常構築との実際の比較と配分判断へ移せるかを確認します。

これは過去の「不足を比較へ戻す」手順の対象を絞った再検証です。通常の次回改訂でも同じことができる可能性があるため、同じ旧案・評価・資料から現行と追加版を改訂15分・別評価10分ずつ一度比較します。具体カードや答えは開発者が与えません。

同じ既知案の再推薦や問いの言い換えだけを成功とはせず、有用で独自な種の獲得は別に判定します。既知案を維持する結果や、未解決の終了も許します。
