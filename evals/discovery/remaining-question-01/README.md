# 既知案への変更後に残った問いを、比較へ移す

**9月13日10:37:19（日本時間）から、現行と追加版の両方で改訂中です。90件の機能検査と型検査を終え、追加文以外の実入力一致を確認しました。方法の有用性と採否は未判定です。**

## 何を変えて試すか

前の[同じ採用枠の代案を比較する試験](../same-slot-alternative-01/README.md)では、両方式とも記事にある同じ代案へ移りました。その後に、別の時点で使う場合や失う役割について問いが残っています。問いを作ることは現行でもできています。

今回は、その保存済みの問いを一件選び、実際の比較と採用枚数・使い方の判断へ進める条件を加えます。例えば「後半には有力な代案があるが、それ以前に必要な仕事をどうするか」という問いなら、必要になる時点で通常構築ができる行動と比べます。代案がまだ使えないだけで旧案を有利にせず、準備や失う役割まで確認します。具体カード・答え・都合のよい手札は開発者が与えません。

これは過去の「不足を比較へ戻す」手順の対象を絞った再検証です。一般的な別用途探索を新しく実装したわけではありません。記事に使い方があることから広い普及を推定せず、既知案の維持・元案を復活させない結果・未解決も許します。

## 検証の手順と現在地

1. 既存の指示と過去3試験を点検し、今回の違いを「既知案へ移った後に残る未比較の問いを一つ、比較へ移す条件」に絞りました。10:28:38に判断基準と上限を固定しました。
2. 前試験の現行側の結果を共通入力にしました。改訂2件・最新評価1件・資料26件、計36ファイルの完全一致を確認しました。保存済みの案を使う試験で、新しい初見入力ではありません。
3. 考案指示だけへ短い文を追加した実装を分けて作りました。既存88件と公開入力等の追加2件、型検査が成功。実入力は追加文と識別値以外が同じで、別評価・調査引き継ぎの公開出力は完全一致しました。
4. 両方式を改訂15分・別評価10分ずつ、一度だけ起動しました。現在は両方の改訂中です。提出と保存を確認してから別担当の評価へ渡し、追加改訂や時間切れのやり直しはしません。実起動後にも資料と指示の差分を照合しました。
5. 回収後、前の比較だけでは答えられなかった問いへ答える比較が保存されたか、その根拠が使う時点や前後の配分を変えたかを別担当が点検します。

## 結果と採否の基準

実装・入力の検査は通りましたが、探索方法の効果は未判定です。通常の次回改訂でも同じ比較ができる可能性があるため、現行も同じ発展へ進めば追加指示の上乗せとはしません。

同じ既知案の再推薦、問いの言い換え、利益を伴わない順番や枚数変更だけを成功とは数えません。対応する状態から比較しても根拠がなければ、既知案と未解決を残します。新しい着想を無理に作らせません。

比較を判断へ戻せることと、有用で独自な種を得ることは別々に評価します。指定手順の成立・試す価値・独自性も分け、各一度の差から一般的な効果を断定しません。有用性が未確認なら本体への追加は保留します。
