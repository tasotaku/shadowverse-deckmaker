# 提出確認まで含めて進捗を自動記録する

**9月13日18:46:18（日本時間）から限定実装中です。採用は未判定です。**

担当が正常終了しても、その後の提出確認が失敗すると、試験全体の表示は実行中のまま残っていました。担当の実行と、提出確認を含む全体工程を別々に記録し、停止後は採否の確認を待つ段階だと分かるようにします。

事前登録された任意の工程だけを使い、既存の呼出しは維持します。終了済みの試験、ユーザーの訂正、他の担当が実行中の工程は保持します。探索結果の合格や手法の採用を自動認定する機能ではありません。

手順は、要件を設計書へ記録、隔離実装、成功・未提出・提出確認失敗・競合の検査、本体への反映と公開操作、既存画面での時刻と状態の確認です。実装は目安15分。開始終了と失敗は担当から実時計を回収して追記します。

[判断条件](protocol.json)を固定しました。記録登録は着手後です。検査は人工入力で行い、実AIや新しい着想の発見力を評価したとは数えません。
