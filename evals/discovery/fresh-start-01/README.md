# 現在の参考構築と説明を、考案前に入力へつなぐ

**開始時の資料取得を接続する試作に着手します。採用・発見力の改善は未判定です。** 前の探索は新弾前の参考構築から始まり、後続調査でその時点差が分かりました。取得と追加の既存機能を開始操作へまとめ、現在の記事を比較に使える状態で考案へ渡します。

記事の取得、40枚と説明の保存、初回入力への反映を一つの入口へ接続します。記事未指定の既存動作は保持。取得失敗は成功にせず、過去の固定入力を変更しません。取得日が新しくても記事の内容まで最新とは限らないため、記事更新表示と限界を残します。

機能の実装と関連検査の後、実記事を読み、初回入力へ同じ本文が渡るか確認します。続いて、答案を渡さない新しい初回探索を一度実施し、現在の通常構築に対して試す理由が残るかを別評価します。機能検査と発見力の結果は分けます。
