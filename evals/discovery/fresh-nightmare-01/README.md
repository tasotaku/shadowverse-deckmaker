## 出た案と、試す理由

案は「返された盤面を監獄で作り直すミッドレンジ」です。参考のミッドレンジ構築から、マクミラン3枚目をアズヴォルト1枚へ替え、他の39枚を維持します。

既存3枚のイステンデッドVSマルチルゲートで得るクレストには、ターン終了時に自分のラストワードを持つカードを破壊する効果があります。これでアズヴォルトを置いたターンに破壊し、通常必要な元コスト1〜8の準備を省いて、破壊履歴から4種類を強化して並べ直す発想です。

別担当が試す理由としたのは、墓場を使わず除去後に攻め直せることです。道中のネクロマンスでマクミランの墓場10を用意できない局面に役割があり、序盤とガロダート3枚を維持する1枠の変更で試せます。復活が小型に偏っても、スケルトンなどが4/4になる利益は残ります。

一方、交換でマクミランの即時3点・突進・守護3体の安定性を失います。復活に守護が含まれない場合があり、クレスト未取得、他のラストワードへの誤爆、超進化権の競合もあります。終了時に並ぶため、そのターンの顔打点と回復は0です。普通の破壊履歴で耐えられる頻度や、ガロダートより役立つ局面は未確認です。
