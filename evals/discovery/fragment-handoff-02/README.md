# 着想の発展を先に保存してから、正式案へまとめる

前回は2方式とも10分で正式案を提出できませんでした。今回は、選ぶ着想・使い道・不足・代償を5分で中間報告として保存し、その報告から10分で正式案へまとめます。通常の発展と、不足を別の役割へ引き受けさせる発展に、同じ資料と時間を渡します。

考案の合計枠は前回の10分から15分へ増えます。工程分割と時間を同時に変えるため、前回との結果差を片方だけの効果とは呼びません。この試行の中での2方式の差を確認します。中間報告の存在だけで有用な種に届いたとは扱わず、正式案・別評価の結果へつなげて判断します。
