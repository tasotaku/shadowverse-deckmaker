# 現在の参考構築を渡して、考案から独立評価まで試す

現在はドラゴンの案を考案中です。参考記事5件から各40枚の構築を5件取得し、通常の構築と何を交換する案なのかを考える資料として渡しました。試す理由のある独自案が残るかは、まだ評価していません。

## 今回試す方法と判断

本体の現行の考案・評価手順を使います。登録済みの主役や2枚の組に限定せず、カードの別用途、複数段の接続、強い構築の役割配分から案を考えます。今回は、直近の比較とは別のドラゴンで、現在取得した参考構築も入力に加えました。

通常構築から得る役割と失う役割、核を引かない場合、PP・手札・場・進化権・相手依存を示せるかを確認します。完全な40枚や一撃20点、実対戦を必須条件にはしません。手順が成立するだけ、資料が保存できただけでは有用な出力と数えません。

この試行の採否は未判定です。比較相手のない1回の試行なので、よい案が出ても、参考記事の取得機能によって発見力が改善したという証明にはしません。

## 検証手順と現在位置

1. 結果を見る前に対象クラス、入力の選び方、5つの判定基準、終了条件を固定しました。
2. 現在のGameWith・Game8のローテーションTier表でドラゴンの記事を4件確認しました。7月保存の参考記事3件との和集合は5件です。5記事すべてを取得しました。
3. 各記事の40枚、出典、記事更新日時、取得時刻を入力へ保存し、初期資料を退避しました。対象113枚と関連99枚を含みます。
4. **考案中**。考案担当を9月10日02:14:35（日本時間）に開始しました。上限15分、期限02:29:35です。案と調査原文を公開コマンドで提出し、保存内容まで確認します。
5. 次に、過去の評価を渡さない別担当が、同じ基準で上限10分の評価を行います。試行推薦・見送りなら終了します。
6. 追加検討になった場合だけ、判断を変える問いについて1回追加調査します。実際の新しい根拠がなければ再評価せず、3回目の考案は行いません。
