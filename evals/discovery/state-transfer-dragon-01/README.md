# 同じ状態での比較をドラゴンの新しい考案へ使う

**通常構築と同じ状態から比べる指示を、考案と別評価を組み合わせる運用へ採用します。** 正式2案・別評価2件まで完了し、最終案には1枠を替えて試す理由が残りました。比較により主役・必要な準備・使う場面が実際に変わったためです。本体への反映を終え、80機能検査・型検査と公開入口の入力一致を確認しました。報告の最終確認も完了しました。実戦の強さや独自性、方法全体の完成を認定した結果ではありません。

## 何を検証しているか

通常構築と同じ開始状態・同じ観察終点で手順を比べ、その差を使い方や採用枚数の判断へ返す指示を試しています。ビショップの保存案で候補になった方法を、ドラゴンの初回考案へ使いました。比較表ができたことだけでは採用せず、正しい比較が判断を変え、試す理由のある種が残ることを開始前の条件にしています。

## 実際に行った手順

1. 保存DBでドラゴン・ローテーションに該当した全3記事を開始前に固定し、全40枚・取得情報・記事説明の計9資料を取得しました。具体的な過去案と評価を初期入力へ追加していません。既存DB・注記・設計原則は既知です。
2. 考案の指示へ比較手順だけを追記した隔離コピーを使いました。評価指示・回答形式・モデル設定は変えていません。実AIの前に80機能検査・型検査と、公開入口で比較指示以外が同じことを確認しました。
3. 初回の考案・別評価を各1回実行しました。制限は考案30分・評価15分です。正式1案・別評価1件を保存でき、初回は手順支持・試用保留・独自性未確認でした。
4. 採用判断を変えうる具体的な問いが残ったため、開始前の分岐条件に従って改訂・別評価を1回だけ追加しました。制限は同じく30分・15分。初回の案・評価・資料を渡し、メイン担当の新しいカード答案は渡していません。
5. 最後の評価と入力保存を確認して採否を決め、未確認事項と全工程の開始・終了を残します。最終の正式回答・元資料・実装・DBの保持と自然終了まで確認できました。

## 最後の評価と採用理由

最後の評価は「条件付きで手順成立・比較試用を推薦・独自性未確認」です。既存の生成札2枚の直接使用は4PPで2点・2回復ですが、追加した1枚と合わせると3PPで5点・2回復・単体へのランダム3点に変えられます。既存の8PP本体を払えない場面を補う、1枠の役割交換として試す理由が残りました。手順だけの成立や資料件数ではなく、この比較と実際の変更を採用理由にしています。

**ただし、提案にある「相手体力3〜7の致死差」は訂正が必要です。** 通常側も生成札2枚の直接使用と波揺花で4点を出せるため、体力3〜4なら通常側も勝てます。まず差を調べる範囲は5〜7であり、その範囲すべてで通常側の未知ドロー込みの最善行動に勝つと実証したわけでもありません。元提案は書き換えず、この訂正を正式な別評価とともに保存しています。

主比較の相手体力14では、実際に顎門を使う優位は未成立です。準備中に回復札を使わずランプする選択もあり、7PPに留まることが避けられないとはいえません。自然な使用機会、提示を減らす損失、非致死後の手札不足を確かめ、損失が重ければ試用推薦を撤回します。独立した方法点検でも、これらを残した限定試用は固定基準に沿い、派生範囲の訂正は主比較や試用理由全体を崩さないと判断されました。

指示単独で誤りを防げると認定したわけではありません。別担当の評価で訂正を拾う運用と組み合わせて採用します。評価資料から旧評価ファイル・採点は除いていますが、提案文には過去の指摘を受けた改訂理由が残るため、過去の判断を完全に伏せた検査とは区別します。
