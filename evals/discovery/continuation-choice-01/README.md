# 同じ核を続ける理由を、判断を変え得る比較へ結ぶ

検証準備中です。前回は中盤と終盤を別々に計算できましたが、序盤に使う資源を終盤にも残せる根拠が不足しました。同じ核を微調整するだけで止まらないよう、改訂前に判断を変え得る比較を一つ選ぶ指示を、現行の方法と比べます。

同じ保存済みの案・評価・資料で、現行Aと変更Bを各一度、改訂15分＋別評価10分で実行します。Bだけ指示を変え、個別カードの答えや期待する採点は渡しません。実装・実AI確認・採用はまだです。

比較から根拠が増え、継続・配分・使い方・別仮説への変更を判断できたかを確認します。同点、説明の追加だけ、別評価未完了なら採用を保留します。既知入力1件であり、一般的な発見力の証明にはしません。[固定条件](protocol.json)。
