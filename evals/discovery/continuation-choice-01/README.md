# 同じ組み合わせを続ける理由を、判断を変え得る比較へ結ぶ

**本採用は保留です。変更版では旧案を続けない理由が具体的になりましたが、試用推薦は現行・変更版とも0件でした。** この報告は、探索方法の採否と検証に使った時間を確認するための記録です。システム全体は未完成です。

同じ保存済みの案・評価・資料を使い、現行Aと変更Bを各一度、改訂15分＋別評価10分の上限で実行しました。Bにだけ「直前の不足に答え得る比較を先に選び、結果から同じ組み合わせを続けるかを判断する」という指示を追加しました。個別カードの答えは渡していません。Aの入力を固定してAを開始し、Bの117件の機能検査・型検査と、追加指示以外の入力一致を確認してからBを開始しました。[開始前に固定した条件](protocol.json)。

試用推薦は「通常構築と比べ、ユーザーが試す理由がある」という別担当の判定です。追加検討は、判断を変え得る未解決の問いが残る段階です。勝率の認定ではありません。

旧案は、生成した妖精を終盤まで持ち、匠の打点につなげる案でした。両方式ともこの組み合わせを見送り、別の主役へ移りました。Bは同じ手札から妖精を生成する場合と通常の除去に使う場合を比べ、妖精2枚を得る代わりに敵2体の処理や残る盤面を失うことを示しました。この比較を旧案の継続見送りへ反映し、別評価もその説明を支持しています。Aも自ら分岐しているので、分岐した事実だけをBの成果には数えません。
