# 指定資料だけの読出し

対象: discovery_read、inquiryの再読検査、公開入口と担当への利用案内。入力packet、旧sources、正式提出・評価、時間指示は変更しない。

1. 正常: source_indexは本文以外の指定6項目、行数・文字数・読むsectionを返す。指定本文を分割して改行を保持し復元できる。
2. 境界: 大きな画像文字列の別資料があっても索引と指定本文に混入せず、sources全体を整形する処理へ戻らない。旧sources出力と固定packetを保持する。
3. 失敗: 未知HASH、不正形式、重複、HASHと内容の不一致、範囲外ページを拒否する。
4. 正常: 調査・照合の公開添付→新版のsource:HASH全文再読→report→finishが成功し、終了後の同じ公開操作証拠で再検査できる。旧sources再読も維持する。
5. 失敗: 別HASH、部分だけ、添付前、報告のない旧packet、混在した行番号で全文を満たそうとする再読は受理しない。終了後の操作記録変更は拒否する。

testスキルの(a)正常、(b)境界、(c)失敗を上記に整理。架空資料と合成processのみで検査し、実AI・実DB・私的ログは使用しない。
