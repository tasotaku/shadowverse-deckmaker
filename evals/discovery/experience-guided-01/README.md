# 保存した経験を参照すると次の考案が良くなるか

過去の案を検索する補助が、次の考案を良くするかを比較します。**従来側の正式1案を別担当が評価中です。経験参照側は考案中で、方法の採否はまだ未判定です。** 同じドラゴンの初期資料を2担当へ渡し、一方だけが過去の正式案・評価・未確認事項を検索します。

カードと参考資料は、以前の検証開始時点の保存版です。5記事・5構築を含む11資料を共通に使います。新しい未知資料の検査ではありません。過去経験は16探索の保存先・316ファイルを固定し、成功案だけを選んで渡すことはしません。

## 手順と判断条件

入力と基準を固定 → 2方式で考案・正式提出 → それぞれ別担当が成立と試す価値を評価 → 以前の案との差を照合 → 採否と工程時間を記録、の順で行います。

考案は各30分、別評価は各15分を上限に、経過時計で開始終了を自動記録します。今回は初回考案での経験利用だけを比較するため、両方式とも追加改訂は行いません。未提出や実行失敗は成功へ置き換えず、そのまま残します。

過去経験を参照する担当には、参照した範囲と、実際に案を変えた点・見送った点を記録させます。旧採否は別評価へ渡しません。案の成立・価値は今回のカード本文と配分から改めて判断し、旧判定が追加資料へ混入した場合は隠さず記録します。

成立すること、試す理由、未発見であることを分け、従来の5基準を維持します。以前の案の再提出・言い換え・計算訂正だけは、新しい発見や実質的改善と数えません。参照ありの側だけが有用な新しい種、又は未解決だった負担を解消した案へ到達し、その経験利用を確認できれば、この入力で有望と判断します。同点・参照未利用・時間条件不適合なら追加手順の本採用は保留です。1組で一般優位やシステム完成は認定しません。
