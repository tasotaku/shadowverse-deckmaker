# 保存した経験を参照すると次の考案が良くなるか

**今回の比較では、経験を参照する手順の本採用を保留しました。** 参照なし・ありの両方式で正式案と独立評価を1件ずつ保存しましたが、試用の推薦は0件ずつでした。両カード案とも、山札の札を消してルリアの検索先を絞る負担に見合う利益を示せず、追加検討が必要という評価です。

過去記録を検索する機能自体は、別の検査で採用済みです。今回は、その検索を初回考案へ加えると良い種が増えるかを調べました。検索できたことと、良い案を作れたことを分けています。システム全体の開発は継続します。

## どういう方法を比べたか

同じドラゴン・ローテーションの初期資料を、別々の考案担当へ渡しました。Aは通常の考案、Bだけが過去の正式案・評価・未確認事項を検索し、どう利用したかも保存する手順です。特定の主役や正解は指定していません。

共通入力は、以前の検証開始時点に保存したカード212件と、5記事・5構築を含む11資料です。現在の環境を新しく調べ直した入力ではありません。参照用の過去記録は16探索の保存先を固定し、成功例だけを選んでいません。

入力固定 → 2方式で考案・正式提出 → 各案の独立評価と、過去案との差・経験利用の照合を並行して実行 → 採否と時間の保存、の順で実行しました。考案は各30分、評価は各15分を上限にしました。初回提案への効果を測るため、両方式とも評価後の改訂は行っていません。

評価担当には、他方の案、比較の狙い、過去の採否、Bの経験利用記録を渡していません。成立すること、試す理由、独自性を分け、従来の5基準を維持しました。基準全文は[固定条件](protocol.json)にあります。

## 結果はどうだったか

両案とも、序盤の低コスト札を残した構築で、ルインの能力により途中で山札の奇数コスト札を消し、以後のルリアの検索先を2種類へ絞る着想でした。配分は異なりますが、独立した別の中心機構を2件発見したとは数えません。

| 比較項目 | A：経験参照なし | B：経験参照あり |
|---|---|---|
| 交換する枠 | バーンドナイト2枚をルイン2枚へ | イランツァ3・ウィルナス1・バハ2を、ルイン2・バトラー2・絶倒2へ |
| 圧縮後の検索先 | リュミオール／イランツァ | リュミオール／バトラー |
| 正式案／独立評価 | 1件／1件 | 1件／1件 |
| 手順の評価 | 指定状態なら一部成立。ただし、そこへ至る手札・山札枚数に誤りあり | 指定した引き順・生存・相手の条件なら成立。説明と次の比較案に訂正あり |
| 試す価値 | 追加検討。推薦0件 | 追加検討。推薦0件 |
| 独自性 | 未確認 | 未確認 |
| 考案の所要時間 | 18分28秒 | 21分01秒 |
| 独立評価の所要時間 | 10分44秒 | 8分49秒 |

Aでは、初手と通常ドローを数えると、記載された道中のT7開始時は手札8枚・山札26枚になります。提出案の手札7枚・山札27枚とはつながりません。未記載の1枚を推測で補わず、正式案と指摘をそのまま残しました。

採用価値の問題は、両案に共通しています。検索しやすくなった札が、提示された決着へどれだけ貢献したかが弱い点です。Aは検索前から主要な決着札を持っています。Bの指定した23点のうち19点も、圧縮前から確保したサガと通常の攻撃札によります。

独立評価は、元の札を普通に使う比較も示しました。Aの指定局面では、ルインを元のバーンドナイトへ戻すと、同じ期間の顔への打点が14点から16点になります。Bの指定局面では、圧縮へ7PPを使う代わりに、手札のサガからそのターンに8点を出せます。この8点比較は、評価担当の補足報告にだけあり、正式評価の判断欄には含まれていません。いずれも、同じ指定局面での条件付き比較です。試合全体の勝率や、圧縮が常に不要という証明ではありません。

Bにも訂正点があります。「SEP補充」は超進化権の補充ではなく、それを消費した手札補充です。また、圧縮札を外す比較で候補に挙げたノマグダラは既に3枚入っており、そのまま増やせません。中心手順の数値会計とは分けて記録しました。詳しい成立条件と比較は[Aの評価](a/review/evaluation.md)・[Bの評価](b/review/evaluation.md)に残しています。

## 過去経験は使われたか

Bは6種類の条件で検索し、成功7回・引数間違いによる失敗1回でした。5改訂と5評価を取得し、正式提出より前に旧ドラゴン案の報告も読出しています。本人は、補充と攻撃改善を分けることや、圧縮を使わない比較を残すために参照したと記録しました。この申告と出力内容は整合していますが、実際に考えを変えた因果まで操作記録で証明することはできません。

過去の18保存物を複製ごとにまとめた10改訂と照合し、A・Bとも単なる再提出には当たりませんでした。ただし、経験を参照しないAも同じ中心の着想へ到達しています。保存範囲に同型がないことは、世界での未発見や未普及の証明ではありません。[照合結果と利用記録](independent-comparison.json)を保存しています。

## なぜ保留し、次に何を直すか

採用条件は事前に「Bだけが有用な新しい種、または未解決の負担を解消した案へ到達し、対応する経験利用も確認できること」と固定しました。今回は両方とも追加検討止まりなので、この条件を満たしません。Bの考案はAより2分33秒長くかかりましたが、担当差や調査量も違うため、経験参照が遅さの原因とは判断しません。

実行工程と記録の保持は確認できました。一方、正しさはAに要訂正、Bは指定条件付きです。評価後の発展は未実施で、有用な種への到達は両方とも未達です。Tierや勝率は認定していません。通常の考案・評価指示、カードDB、過去の評価は変更していません。

次の改善は、今回残った「追加した仕組みが、元の行動よりどこで得になるか」を、採用配分や使い方の変更へ返す工程を対象にします。既存の改訂機能でできる部分と不足を点検し、最小の実装と次の検証条件を決めます。現時点では次の方式は未採用です。
