# 資料だけを補った再評価

2026-09-08。イマリ17枚型の結果は **conditional / develop / unconfirmed**。
元の固定期待値dropとの一致は今回もFAIL。資料3件の受け渡しと引用は3/3件で確認した。
これは入力の補充が判断に与える影響の1回の検査で、未知の発見力や強さの検査ではない。

旧packetの全項目が同じで、sourcesと引用形式の案内だけを追加したことを機械照合した。
案・カード・設計原則・評価指示・回答例は変えていない。新しい別担当が固定資料だけを読んで評価し、
公開CLIのreviewとreportで保存を確認した。Webは再取得していない。

追加したのは、序盤・対面の使用者経験、繰り返す展開への対応という反対側の材料、当時の比較元の部分抜粋。
過去のAIの採否ラベルは追加していない。比較元の完全な旧40枚と、過去に実施した調査履歴は依然欠けている。
結果が変わらなかったことだけから、判断基準の甘さを唯一の原因と確定しない。

別担当は、当日イマリを出す補足ではニューロンが自動進化しない点も指摘した。
主例7PPの成立とこの補足は区別する。次の問いには、種別の純増8を交換総数と読む余地がある表現も残った。
旧・新の全リストを確認する前に、交換した個々の札や総数を確定しない。

`protocol.json`は事前の検査範囲、`unchanged-check.json`は旧資料との照合、`sources.json`は追加入力。
`packet.json.gz`と`review-response.json`は実際の資料と回答、`evaluation.json`は範囲付きの採点。
`manifest.json`で保存物を照合できる。古い2件の採点は書き換えていない。
