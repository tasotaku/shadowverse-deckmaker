## 1. アンカー候補（ヘッドルーム大）

### 奥夜花・シャクドウ [10554120] ナイトメア/F/cost10/4/4
> 「自分の手札すべてをデッキに戻す。自分のデッキからX枚を引く。Xはこれでデッキに戻した枚数である。その後、自分の手札に4枚以上同じコストがあるなら、相手の場のフォロワーすべてと相手のリーダーに4ダメージ。」を2回行う。超進化時: 同能力再発火。

- アトム: `[ファンファーレ] → {山札戻し(手札全) ∧ ドロー(量=X, X=戻した枚数) ∧ [手札に同コスト≥4] → ダメージ(相手F全+相手リーダー, 4)} ×2`
- ヘッドルーム: 素≈0（手札が揃わなければ引き直しだけ）/ 最大=リーダー8点+全体8点、超進化込みで16点=OTK級 → **アンカー確定級**
- 要求コンパイル: `手札(引き直し後10枚★)に同コスト≥4` — **既存3種で表せない**。カード供給でなく**デッキのコスト分布**で満たす確率的要求 → **発見: 要求の4種目「構築制約型」が必要**
- 噛む供給の型: デッキ純化（特定コスト帯に寄せる）・コスト変換

### 陽と月の薔薇・セレス [10854120] ナイトメア/F/cost5/1/4
- アトム: `[ファンファーレ][ネクロマンス20] → コスト-2(自手札のナイトメアカード全)` / `[交戦時] → ダメージ(交戦相手,4)` / `[自ターン終了時] → 回復(自リーダー,4)`
- ヘッドルーム: 手札次第でPP十数点分の圧縮=大 → アンカー
- 要求: `墓場≥20 by T5〜7`（蓄積型・大N）。**算術デモ**: 自然増≈1.5/T（プレイ+死亡）→T6で約9。ギャップ≈11 → 墓場+専用供給が3積み×2種は必要 → 「専用構築でギリ届く」が機械で出る
- 供給（自身も供給）: `コスト-2一括` = 多重プレイの燃料（コンボ/連携カウンタ系と噛む）

### ビギンズブレイダー・アマツ [10114130] エルフ/F/cost3/2/2
- アトム: `[ファンファーレ] → バフ(自身, +X/+X, X=自手札の妖精Fの枚数)` / `[進化時] → ダメージ(相手F,1)×X回`
- ヘッドルーム: 手札上限★まで＝3コス8/8守護+8点除去級 → アンカー
- 要求: `手札に妖精Fを溜める`（蓄積型・ゾーン=手札・属性=妖精）→ 噛む供給: フェアリー手札生成

### 破壊の継承者・アクシア [10374110] ネメシス/F/cost3/2/4
- アトム: `常在 → 守護 ∧ 破壊耐性★R7` / `[超進化時] → ダメージ(相手リーダー, X=自場の他カード枚数) ∧ 破壊(自場の他カード全)`
- ヘッドルーム: 素の打点はX≤4★R5で中。ただし**副作用が本体級**: 全自壊=`味方破壊イベント×N ∧ 墓場+N` → ラストワード一斉起爆・ネクロ燃料の**供給者でもある**
- 要求: 超進化権★R4 + `自場のカード枚数≥N`（存在/蓄積。**アミュレットも数える**→アミュ設置が供給になる）
- **発見**: アンカーと供給の两面持ち。デルタ分解が副作用供給（LW起爆）を機械で出せる好例

### 生滅の技巧・ネハン [10453110] ナイトメア/F/cost6/2/4
- アトム: `[ファンファーレ] → 進化(自場の進化前F全) ∧ ダメージ(自リーダー,2)` / `常在 → ドレイン`
- ヘッドルーム: 素0（盤面なし）/ 最大=進化時能力×4体一斉+盤面バフ → アンカー
- 供給（両面）: `進化権踏み倒し×N`・`進化時トリガ一括起動` — 狭くて強い供給（ハブでない）
- 要求: `自場に進化前F（できれば強い進化時持ち）を複数`（存在型×幅）

## 4. §10検証の所見

1. **型の不足（v1で直す）**
   - 要求に4種目 **「構築制約型」** を追加（シャクドウ: デッキ分布への確率的要求）
   - 蓄積型の変数源にゾーン以外の **履歴カウンタ**（破壊された数）・**コンボ/連携カウンタ** を許す
   - `【FF】と同じ能力が働く` = アトムの参照コピー（進化時→FF再発火）。展開して二重登録でよい
   - アクト/モードはプレイ様式スロット（当面は要件欄に註記で足りる）
2. **創発供給**: 正常の侵食のデッキ純化・アクシアのLW一斉起爆、どちらも**デルタ分解から機械導出できた**。LLMの意味解釈なしで取れる感触は設計通り
3. **ヘッドルームランク**: シャクドウ(OTK級) > セレス/アマツ/ネハン(条件付き大) > アクシア(素は中・副作用大) > 大剣竜(ゲート有・天井小=非アンカー) > バニラ(0)。主キー=最大値・希少度はゲート、の並びが実カードで機能
