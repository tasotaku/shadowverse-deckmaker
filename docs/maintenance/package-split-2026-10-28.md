# 機能別パッケージへの分離（2026-10-28）

## 配置

従来の実装66モジュールを、対戦環境33・デッキ探索18・データ取得整形9・共通6へ全件割り当てた。各領域にパッケージ定義を追加したため、Pythonファイルの総数自体は減らさない。ルート直下はパッケージ定義と互換層の2ファイルだけとする。

- `battle_env`: 対戦処理、対戦AI、対戦検証、対戦画面と固定資料。
- `search`: アンカーの要求照合・組合せ探索、仮説の改訂と評価。
- `data_access`: 公式・公開データの取得、効果・タグの取込と整備。
- `common`: DB、制限時間付き実行、実験記録。記録画面と定義もここへ配置。

新しい実装間の参照と現行ドキュメントのコマンドは正規の配置を使う。過去のimport・`python -m svdeck.explore` 等は単一の互換層で正規実体へ転送する。旧名のファイルを66個残す方式や、別々に状態を持つ実装コピーは作らない。
過去の `docs/evidence`・`evals` の記録と凍結実装は変更しない。DB・注記・保存済みの探索結果の移動も行わない。
