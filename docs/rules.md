## ルール索引

### フォーマット（2026-07-05ユーザー確定）
- **ローテーション** = 直近6弾＋ベーシックのみ / **アンリミテッド** = 全カード
- 合法性は `card.is_include_rotation` で機械判定できる
- アンリミの種も対象として問題ない。ただしカードプールが広い分、相対的に高いカードパワーが要求される

### ターン・PP・進化権
- **覚醒** = 自分のPP最大値7以上（確定）
- **進化権(EP)・超進化権(SEP)**: 先攻後攻とも2個ずつ。進化=先攻T5/後攻T4から、超進化=先攻T7/後攻T6から（確定）
- **エクストラPP**: 後攻のみ。そのターンだけPP+1。T1〜5で1回・T6以降で1回・使うタイミングは任意（確定）

### ゾーン
- 場 / 手札 / 山札 / 墓場のみ。**EXエリアは存在しない**（確定）
- 盤面上限5枚・手札上限9枚（2026-07-05ユーザー確定）
- **手札上限9のときに引いたカードは捨てられ墓地カウンタ+1**（2026-07-05ユーザー確定。
  意図的な「溢れさせ」は墓場燃料になりうる）

### 墓場＝枚数カウンタ（2026-07-05ユーザー確定）
- 墓場は**実体ゾーンではなくただの数字**。何がそこへ行ったかは一切追跡されない
- 増加: フォロワー死亡+1 / アミュレット破壊+1 / 手札を捨てる+1 / スペル使用+1 /
  手札上限超過で溢れたカード+1（すべて2026-07-05ユーザー確定）
- **自然増の速度はデッキ依存・PP単位で見る**（2026-07-06ユーザー確定）: 墓場は専用構築なら
  **1PPあたり約0.5**増える（累積PP≈36のT8で約18）。汎用デッキなら1ターン1枚程度。
  連携も同様に**1PPあたり1連携級のカードが多く**、専用構築なら連携20をT8前後で達成しうる。
  ターン単位の固定レートで見積もるのは誤り
- **ネクロマンスN** = 墓場カウンタをN消費（減る）。複数のネクロカードはカウンタを取り合う（確定）
- 「墓場から特定カードを取る」という理解は誤り。破壊されたカードを参照する能力は**破壊履歴**（別系統）を見る

### 破壊履歴・リアニメイト（2026-07-05ユーザー確定）
- **リアニメイト(N)** の対象 = **このバトル中に破壊された**自分のフォロワーのうち元コストN以下で**最大**の1枚
  （プレイヤーは選べない。公式説明文準拠）
- **手札から捨てられたカードは対象外**（捨ては破壊ではない。墓場カウンタは+1されるが破壊履歴には載らない）。消滅も対象外
- **墓地カウンタを消費しない**（説明文にコスト記述なし）。ネクロマンスとの資源競合は存在しない
- 「捨てて装填→リアニメイト」型のコンボは全部不成立

### 死者（2026-07-05ユーザー確定）
- 死者tribeを印刷で持つのはトークン3種（スケルトン/ゴースト/腐臭のゾンビ）のみ
- **リアニメイトで場に出たフォロワーは追加で死者・タイプを持つ**（公式説明文明記）
- つまり「死者」は静的な種族タグ＋動的な付与の両方であり、tribeテーブルの静的照合だけでは判定できない

### 進化の誘発（公式用語集で確定・2026-07-05）
- **【進化時】** = 「EPを使って進化したときやSEPを使って超進化したときに働く能力」（公式文）
  → **効果による自動進化では誘発しない**
- **「〜が進化したとき」**（イベント参照表記）は自動進化でも誘発する
- 同様に【超進化時】も、効果付与の自動進化（通常進化扱い）では誘発しない

### 盤面継続の原則（2026-07-05ユーザー確定）
- **シャドバの盤面は残らない**。進化権があるため盤面処理は容易で、盤面が残る状況はむしろ負けに近い
  （だから皆処理できる構築にする）
- なんの残存性も持たないフォロワーが**次の自分ターンまで生存する前提**は置けない。
  生存を仮定してよいのは残存性の理由がある場合のみ（潜伏・威圧・オーラ等。守護裏やスタッツ超過は理由にならない）
- アミュレットは攻撃対象にならないためこの原則の適用外（除去手段が限られる）

### オーラと「能力によって破壊できない」は別物（2026-07-05確定）
- **オーラ** = 「相手の能力で選ばれない。」（公式定義・ability_keyword）。破壊耐性ではない
- 「能力によって破壊できない」はアルメス等の**カード個別テキスト**（オーラと併記されていても別能力）。
  字義通り破壊効果のみ無効で、ダメージ・消滅は通ると読む
- 旧仮定R7はこの2つを混同していた（解消済み）
