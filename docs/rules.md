## ルール索引

### フォーマット（2026-07-05ユーザー確定）
- **ローテーション** = 直近6弾＋ベーシックのみ / **アンリミテッド** = 全カード
- 合法性は `card.is_include_rotation` で機械判定できる
- アンリミの種も対象として問題ない。ただしカードプールが広い分、相対的に高いカードパワーが要求される

### ターン・PP・進化権
- **覚醒** = 自分のPP最大値7以上（確定）
- **進化権(EP)・超進化権(SEP)**: 先攻後攻とも2個ずつ。進化=先攻T5/後攻T4から、超進化=先攻T7/後攻T6から（確定）
- **エクストラPP**: 後攻のみ。そのターンだけPP+1。T1〜5で1回・T6以降で1回・使うタイミングは任意（確定）
- **PP最大値の上限は10**（2026-07-07ユーザー確定）。効果による「PP最大値+1」（ゾーイ等）も上限10を
  超えて累積しない＝10到達を早めるランプであり、11以上のPPは作れない

### 進化後の数値と攻撃（2026-09-10公式本文確認）
- 通常進化すると、フォロワーの攻撃力・体力はそれぞれ2増える。
- 進化したフォロワーは、場に出たターンでも相手フォロワーを攻撃できる。進化だけでは、
  場に出たターンの相手リーダーへの攻撃は可能にならない。疾走など別の能力がある場合は、その本文も確認する。
- EPを使う操作の解禁ターンと、進化したフォロワーに適用する上記の一般則は区別する。
  カードの能力で進化する手順では、その能力の条件・順序を別に確認する。
  出典: [公式「対戦する」の進化](https://shadowverse-wb.com/ja/system/cardbattle/battle/)、
  [公式カードページの共通用語「進化」](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10071310)。
  前者は本文の直接取得、後者は公式検索掲載本文を確認。
  個別の効果進化手順を実機で操作した記録ではない。

### 体力への作用（ダメージ／回復／体力±の区別・2026-07-12ユーザー確定）
効果として別物なので数値化でも1つに潰さない（design.md §11.10）:
- **ダメージN** = 現在体力を減らす。**バリアで防がれる**（1回分カット）
- **回復N** = 現在体力を戻す。**最大体力を超えない**（キャップあり）
- **体力±N** = 直接増減。**貫通**（バリアを無視）し、＋は最大体力も動かしうる（リンクル系＝リーダー最大体力変更）
- ダメージと「体力−」は結果は同じだが、バリアで防げるか（ダメージ）／貫通か（体力−）で区別される

### 割り振り（ダメージの範囲・2026-07-12ユーザー確定）
- **相手盤面の右（古いフォロワーから）順に、各フォロワーの体力分ずつ、総量Xを使い切るまで倒していく**
- だから「N体」でなく **総量X** を持つ（design.md §11.10 の範囲=割り振り(総量X)）

### ゾーン
- 場 / 手札 / 山札 / 墓場のみ。**EXエリアは存在しない**（確定）
- 盤面上限5枚・手札上限9枚（2026-07-05ユーザー確定）
- **手札上限9のときに引いたカードは捨てられ墓地カウンタ+1**（2026-07-05ユーザー確定。
  意図的な「溢れさせ」は墓場燃料になりうる）

### 初期手札と通常ドロー（2026-09-10公式本文確認）
- 初期手札は4枚。引き直しの後、自分のターン開始に山札から1枚を引く。
  出典: [公式「対戦する」の引き直し・ターン開始](https://shadowverse-wb.com/ja/system/cardbattle/battle/)。
- この2つから、ほかの増減がなければ第1ターンの通常ドロー後は5枚となる。
  4枚は初期配布の枚数であり、通常ドロー後の枚数とは区別する。途中の指定手札から計算を始める場合は、その時点までの増減も別に示す。

### 墓場＝枚数カウンタ（2026-07-05ユーザー確定）
- 墓場は**実体ゾーンではなくただの数字**。何がそこへ行ったかは一切追跡されない
- 増加: フォロワー死亡+1 / アミュレット破壊+1 / 手札を捨てる+1 / スペル使用+1 /
  手札上限超過で溢れたカード+1（すべて2026-07-05ユーザー確定）
- **自然増の速度はデッキ依存・PP単位で見る**（2026-07-06ユーザー確定）: 墓場は専用構築なら
  **1PPあたり約0.5**増える（累積PP≈36のT8で約18）。汎用デッキなら1ターン1枚程度。
  連携も同様に**1PPあたり1連携級のカードが多く**、専用構築なら連携20をT8前後で達成しうる。
  ターン単位の固定レートで見積もるのは誤り
- **ネクロマンスN** = 墓場カウンタをN消費（減る）。複数のネクロカードはカウンタを取り合う（確定）
- 「墓場から特定カードを取る」という理解は誤り。破壊されたカードを参照する能力は**破壊履歴**（別系統）を見る

### 破壊履歴・リアニメイト（2026-07-05ユーザー確定）
- **リアニメイト(N)** の対象 = **このバトル中に破壊された**自分のフォロワーのうち元コストN以下で**最大**の1枚
  （プレイヤーは選べない。公式説明文準拠）
- **手札から捨てられたカードは対象外**（捨ては破壊ではない。墓場カウンタは+1されるが破壊履歴には載らない）。消滅も対象外
- **墓地カウンタを消費しない**（説明文にコスト記述なし）。ネクロマンスとの資源競合は存在しない
- 「捨てて装填→リアニメイト」型のコンボは全部不成立

### 死者（2026-07-05ユーザー確定）
- 死者tribeを印刷で持つのはトークン3種（スケルトン/ゴースト/腐臭のゾンビ）のみ
- **リアニメイトで場に出たフォロワーは追加で死者・タイプを持つ**（公式説明文明記）
- つまり「死者」は静的な種族タグ＋動的な付与の両方であり、tribeテーブルの静的照合だけでは判定できない

### 進化の誘発（公式用語集で確定・2026-07-05）
- **【進化時】** = 「EPを使って進化したときやSEPを使って超進化したときに働く能力」（公式文）
  → **効果による自動進化では誘発しない**
- **「〜が進化したとき」**（イベント参照表記）は自動進化でも誘発する
- 同様に【超進化時】も、効果付与の自動進化（通常進化扱い）では誘発しない

### 盤面継続の原則（2026-07-05ユーザー確定）
- **シャドバの盤面は残らない**。進化権があるため盤面処理は容易で、盤面が残る状況はむしろ負けに近い
  （だから皆処理できる構築にする）
- なんの残存性も持たないフォロワーが**次の自分ターンまで生存する前提**は置けない。
  生存を仮定してよいのは残存性の理由がある場合のみ（潜伏・威圧・オーラ等。守護裏やスタッツ超過は理由にならない）
- アミュレットは攻撃対象にならないためこの原則の適用外（除去手段が限られる）

### ファンファーレの発動条件（2026-07-05ユーザー確定・2026-07-06転記）
- ファンファーレは**手札からコストを支払ってプレイした時のみ**発動する
- **直接召喚・デッキから出す・リアニメイト・トークン召喚では発動しない**（公式定義「手札から
  プレイして場に出たときに働く能力」の帰結。サンダルフォンの直接召喚で誤解が出たため明記）
- 能力やラストワードによる単なる「場に出す」もプレイではないため発動しない
  （2026-08-26、混迷の監獄・アズヴォルトの相方選定でユーザー再確認）

### コスト軽減はエンハンス等の代替コストに効かない（2026-07-07ユーザー確定）
- 手札のコスト軽減（セレスの-2等）が下げるのは**カードそのもののコストのみ**
- **エンハンス・アクセラレート・結晶などの類は別のコストとして設定されており、軽減の対象外**
  （例: 渇欲のネクロマンサーのエンハンス8は、本体コストが下がっても8のまま）

### アクセラレートでプレイしたカードの元コスト（2026-08-26ユーザー公式Q&A確認）
- アクセラレートでプレイした場合、プレイ履歴上の「元のコスト」はカード本体の印刷コストではなく、
  **そのアクセラレートのコスト**として扱う
- 例: 『最古の獄卒』をアクセラレート1でプレイした場合、「元のコスト1のカードをプレイした」扱い。
  本体の元コスト6をプレイしたことにはならない

### 同名クレストは重複しない（2026-07-30ユーザー確定）
- 同じ名前のクレストを複数持つことはできない
- 既に持っているクレストと同名のクレストを再取得しても、同じ能力が複数回働く状態にはならない
- したがって、同じクレストを与えるフォロワーをコピー・再使用しても、クレスト能力の出力は倍増しない

### モード選択と信仰値（2026-07-30ユーザー確定）
- 1枚のカードでモードを複数選んでも、信仰値の増加は**そのカード1枚につき+1だけ**
- 「選ぶモードの数を+1する」効果を複数回得ても、元の選択肢数を超えて選ぶことはできない
- したがってシャム＝ナクアを2回起動する上積みが生まれるのは、モードの選択肢が3つ以上あるカードだけ

### オーラと「能力によって破壊できない」は別物（2026-07-05確定）
- **オーラ** = 「相手の能力で選ばれない。」（公式定義・ability_keyword）。破壊耐性ではない
- 「能力によって破壊できない」はアルメス等の**カード個別テキスト**（オーラと併記されていても別能力）。
  字義通り破壊効果のみ無効で、ダメージ・消滅は通ると読む
- 旧仮定R7はこの2つを混同していた（解消済み）
