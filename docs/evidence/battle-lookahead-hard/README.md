# 複合能力・多ターン・5対5の追加検証

2026-09-24。**正解付き134局面は全件一致。一方、分岐の多い5対5の2局面は未完了で、先読み性能は未達。**

テストを追加し、独立参照との照合と時間・メモリ計測を実行した。探索本体は変更していない。通常AIがどの深さまで完了したかと、正解を確認できたかは分けて記録した。

## 正解を確認できた範囲

生成集合は3ターン80件、2ターン32件、1ターン16件。初手で勝敗評価が変わる37件、非整数の勝敗確率を持つ8件を含む。3ターンケースの最適方策が次の自分のターンまで到達したのは57件。生成集合の方策は全724辺の再生に成功した。成功seedだけを選別していない。

手作りケースは、バリアへの指定ダメージ→古い順の割り振り、召喚→疾走付与、突進フォロワー→必殺付与、ランダム除去と指定除去の温存などを含む。6件中5件は1・2ターンでは勝利未確定、3ターンで勝利確率1となる。残り1件は即時勝利との対照ケース。

入力作成担当は探索本体を読まず、別担当の既存参照探索で期待値を計算した。参照と製品は別プロセスで実行し、全初手の有理数確率を照合。参照も同じBattleを使うため、実ゲームの全ルールの独立証明ではない。バリアと必殺の裁定などは現Battleの仕様に基づく。

## 完走できなかった範囲

5対5は双方とも5体が攻撃可能、各6枚手札、PP5、初手24候補。指定・ランダム・古い順の割り振り・確定除去・召喚・付与と5種類の能力を同時に含む。置物で盤面サイズを水増ししていない。

通常AIの初回測定は約1.71秒・2.01秒、プロセス最大約42 MiB。合法な一手を返し、未完了と上限理由を表示したが、**0/3は1ターンの探索も完了していない**という意味。単発の行動評価が完了した範囲を使っており、3ターンの最善手とは扱わない。

独立参照もこの2件では各30秒で打切りとなり、正解は未確定。表の状態数・時間は製品探索の実測で、正解一致の証拠ではない。上限を増やすだけでは今回の2件を解き切れなかった。

## 測定の意味と記録

生成128局面の探索時間は3.01〜520.46 ms、プロセス生涯ピークは22.42〜27.84 MiB。手作り正解付き6件は19.43〜110.50 ms。これらを大盤面の性能保証には使わない。

Windows / Python 3.12。2 worker並列実行。メモリは各PythonプロセスのWindows PeakWorkingSetSizeで、探索だけの増分でも2プロセス合計でもない。製品と参照のメモリは別プロセスで計測する。探索時間に起動・入力正常化・保存・出力方策の再生は含まない。外側の経過時間も各check.jsonへ保存した。制限は協調的な中断であり、30秒設定の実測は約30.003秒だった。
