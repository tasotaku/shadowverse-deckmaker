# カード効果スキーマ抽出プロンプト（ベクトル化用・v5・2026-07-12）

LLM抽出器への指示書。**カード1枚の能力テキスト（skill_text）を、閉じた効果スキーマ（design.md §11.10）へ写す。**
出力は下記スキーマのJSON。設計の正本は design.md §11、ルールは rules.md。ここは抽出器が単体で読める要約＋規約。

※これは**戦闘力ベクトル化(§11)専用**の抽出。マッチング用のアトム抽出（§4-6・`extraction-prompt.md`）とは別物。

## 役割と基本姿勢

Shadowverse: Worlds Beyond のカード能力を、**型の決まった効果**に落とす。ルールで文字列を解析するのでなく、
**意味を理解して型に写す**のが仕事（算数=軸への集計は下流のプログラムがやる。ここは事実の翻訳だけ）。

- **意味で判断する**（表記ゆれに引きずられない）。
- **収まらない物は捨てず、必ず `その他` に自由記述で出す**（silent drop 厳禁。欠落は下流で発見できない）。
- **DBが持つ確定値は書かない**: カードの素のコスト・攻撃・体力は入力に付いている。効果には「効果で変動する分」だけ書く。
- **迷ったら出しすぎに倒す**（過剰は人が削れる。欠落は気づけない）。

## ルール前提（確定・この通りに解釈する）

| ルール | 内容 |
|---|---|
| 覚醒 | 自分のPP最大値7以上 |
| 進化権/超進化権 | 先攻後攻とも各2個。進化=先攻T5/後攻T4、超進化=先攻T7/後攻T6から |
| ファンファーレ | **コストを払い手札からプレイした時のみ**発動。直接召喚・リアニメイト・トークンで出た体では発動しない |
| 進化の区別 | 【進化時】は進化権を使った進化でのみ。効果テキストの「進化する」は進化権を使わない自動進化 |
| ダメージ/回復/体力 | **ダメージ**=現体力減・バリアで防がれる ／ **回復**=現体力増・最大まで ／ **体力±**=直接増減・貫通（rules.md） |
| 割り振り | 相手盤面の右（古い順）から体力分ずつ、**総量X**を使い切るまで倒す。「N体」でなく総量を持つ |
| 手札に加える/引く | 「デッキから引く」＝山札から取る＝リソース動作「引く」。「手札に加える」＝新規＝リソース動作「生成」 |
| ゾーン | 場 / 手札 / 山札 / 墓場 の4つのみ |
| マークアップ | `<color=Keyword>〜</color>`=公式キーワード、`<hr>`=能力区切り、`<ev>/<sev>`=進化後/超進化後能力 |

## 出力スキーマ（design.md §11.10 v5）

カード1枚 = 次のJSON。`効果` は効果オブジェクトのリスト。**各効果に `条件`（発動要件の配列）を必ず付ける**。
同じ種類を複数持てる（例: FF版と進化時版で処理2つ = 2オブジェクト）。

```json
{
  "card_id": <int>,
  "自身": {"攻": <int>, "体": <int>, "特性": ["守護", "1ターンに2回攻撃", ...]},
  "効果": [ <効果オブジェクト>, ... ]
}
```

- `自身`: フォロワーのみ（攻体は入力のDB値をそのまま）。**特性は無条件のものだけ**（守護・疾走等のキーワード＋
  キーワードでない常在も自由記述で横並べ）。**条件で付く/変わる特性・スタッツは `自身` でなく `処理`(対象=自身)** で書く。
  スペル・アミュレットは `"自身": null`。
  - **常在／オーラ／供給的な能力も、無条件なら特性に自由記述で**入れる（この体が常に持つ性質だから）。
    例: 「1ターンに2回攻撃」、カローン「自分の死者・フォロワーが場に出たとき守護を付与」、「自分の他の◯◯を+1/+1」。
    ＝内部トリガ（〜が出たとき）は発動条件でなく能力の一部。一方 **FF/進化時/攻撃時など"1回発火する能動効果"は処理**で書く。

効果オブジェクトは `種類` で分岐（該当キーだけ入れる）:

```
■ 随伴（自分の場に追加の体を出す。トークン・召喚・直接召喚・変身で出る体）
{"種類":"随伴", "条件":[...], "何を":"<カード名 | 選択条件>", "数":<int>, "付与":{"攻":<±int>,"体":<±int>,"特性":[...]}}
   - 出る体の中身は書かない（そのカードは別途参照）。名前だけ。不定なら「何を」に条件（"リアニメイトN" 等）
   - 付与 = 出した体に足すもの（無ければ省略）

■ 処理（場のフォロワー/リーダーへ働きかける）
{"種類":"処理", "条件":[...], "繰り返し":<int>,
 "対象":["自フォロワー"|"相手フォロワー"|"自アミュレット"|"相手アミュレット"|"自リーダー"|"相手リーダー" を1つ以上],
 "範囲":{"型":"選択"|"ランダム"|"全体"|"全体(自身除く)"|"割り振り", "数":<int>, "総量":<int>},   // フォロワー/アミュレット対象時。単体=選択・数1
 "効果":{"攻":<±int>, "体":<±int>, "特性付与":[...], "ダメージ":<int>, "回復":<int>, "除去":"破壊"|"消滅"|"変身"|"バウンス", "変身先":"<名>"}}
   - 盤面とリーダー両方に効くなら対象を複数入れる（例 相手フォロワー＋相手リーダー、範囲=割り振り総量X）
   - 「場の他のフォロワーすべて」＝自分＋相手のフォロワーで、自身を除く → 対象=[自フォロワー,相手フォロワー]・範囲型="全体(自身除く)"
   - 「場のカード」＝フォロワー＋アミュレット両方 → 対象に両方を入れる（例「場の他のカード3枚破壊」=[自フォロワー,相手フォロワー,自アミュレット,相手アミュレット]・範囲=選択3）
   - 効果は該当キーのみ。バリアは特性付与に入れる
   - **繰り返し**: 同じ効果をN回行うなら `"繰り返し":N`（省略=1）。ブロックごと反復ならブロック内の各効果に付ける

■ リソース（手札にカードを得る）
{"種類":"リソース", "条件":[...], "動作":"引く"|"生成", "何枚":<int|"X:説明">,
 "生成種別":"特定"|"コピー"|"参照"|"変身", "生成対象":"<カード名 or 説明>", "元":"<変身元の説明>"}
   - 引く=山札から。生成=それ以外。特定=固定カード名／コピー=何かの複製／参照=状態依存(破壊された味方等)／変身=手札のカードを別カードへ

■ 手札処理（手札のカードを変える）
{"種類":"手札処理", "条件":[...], "対象":"<選択N枚 | 全体 | 条件(左からN・最高コスト・コストX以下・種族…)>",
 "効果":{"コスト":<±int>, "攻":<±int>, "体":<±int>, "特性付与":[...]}}

■ デッキ処理（山札のカードを変える。非公開なので選択不可）
{"種類":"デッキ処理", "条件":[...], "対象":"<全体 | 条件(…)>", "効果":{"コスト":<±int>,"攻":<±int>,"体":<±int>,"特性付与":[...]}}

■ クレスト（遅延の入れ物。リーダーに付くカウントダウン付き効果）
{"種類":"クレスト", "条件":[...], "対象":"自"|"相手", "カウントダウン":<int|null>, "効果":[ <処理オブジェクト…> ]}
   - クレスト付与そのもの。中の効果はネストした処理で書く。カウントダウン無し=null

■ 資源（貯めて使う燃料。打点でも体でもカードでもない）
{"種類":"資源", "条件":[...], "資源種類":"PP"|"進化権"|"超進化権"|"スペルブースト"|"土の印"|"信仰"|"墓場"|"カウント", "量":<±int>}
   - 産出/回復=＋、消費=−。「覚醒・エンハンス・融合・連携・アクセラレート・結晶・土の秘術」は資源でなく"条件"側へ

■ その他（上のどれにも収まらない。妨害・デッキ生成・変則効果）
{"種類":"その他", "条件":[...], "記述":"<自由記述>"}
```

## 抽出規約

1. **`<hr>` 区切り・文単位で分解**。1つの効果 = 1オブジェクト。「AしてBする」は原則2つに割る。
2. **条件を全部記録**: トリガ（FF/ラストワード/進化時/超進化時/攻撃時/交戦時/ターン終了時…）、リソースゲート
   （覚醒/ネクロマンスN/スペルブーストN/エンハンスX/コンボN…）、状態（場に◯◯がある…）。FFも省略しない。
   - **条件はトリガ/ゲート/状態の語だけ**。範囲情報（自身を除く）や反復（2回）を条件に混ぜない＝それぞれ範囲・繰り返しへ。
3. **攻撃力の行き先は変換しない**。疾走→顔・突進→盤面のような「攻撃をどこに振るか＋代償」は解釈せず、**特性として事実だけ**書く（下流が解く）。
4. **トークン・召喚・変身で出る/生成されるカードは名前だけ**。そのカードの中身（スタッツ・効果）は書かない＝別途参照。
5. **お膳立て**（手札のカードを別カードに変身: 例ローズ→薔薇の閃撃）は **リソース・生成種別=変身** で書く（生成対象=なる先カード名）。
6. **DB確定値（コスト・素の攻体）は効果に書かない**。`自身` の攻体だけ入力値を写す。
7. **1枚に複数版**（FFと進化時で別の処理）はそれぞれ別オブジェクトに、`条件` で区別。

## 例

**豊麗なるローズクイーン**（9コス6/6フォロワー: FF手札のコスト2以下エルフを薔薇の閃撃に変身 / 守護 / 1ターンに2回攻撃）
```json
{"card_id":10114120,
 "自身":{"攻":6,"体":6,"特性":["守護","1ターンに2回攻撃"]},
 "効果":[
   {"種類":"リソース","条件":["ファンファーレ"],"動作":"生成","生成種別":"変身","生成対象":"薔薇の閃撃","元":"手札のコスト2以下エルフすべて","何枚":"X:該当枚数"}
 ]}
```

**薔薇の閃撃**（1コス0/0スペル: 相手フォロワー1枚か相手リーダーに3ダメージ）
```json
{"card_id":90014310,"自身":null,
 "効果":[
   {"種類":"処理","条件":[],"対象":["相手フォロワー","相手リーダー"],"範囲":{"型":"選択","数":1},"効果":{"ダメージ":3}}
 ]}
```

**混融の継承者・シャム＝ナクア**（2コス2/2: FF信仰-10して信仰に「選ぶモード数+1」を持つ / 超進化時 相手フォロワー1体を破壊し同名を手札に）
```json
{"card_id":10354110,
 "自身":{"攻":2,"体":2,"特性":[]},
 "効果":[
   {"種類":"資源","条件":["ファンファーレ"],"資源種類":"信仰","量":-10},
   {"種類":"その他","条件":["ファンファーレ"],"記述":"自分の信仰に『選ぶモードの数+1』を付与"},
   {"種類":"処理","条件":["超進化時"],"対象":["相手フォロワー"],"範囲":{"型":"選択","数":1},"効果":{"除去":"破壊"}},
   {"種類":"リソース","条件":["超進化時"],"動作":"生成","生成種別":"参照","生成対象":"破壊したフォロワーと同名","何枚":1}
 ]}
```

## 出力形式

**入力カードごとに上記JSONを1つ**。複数カードならJSON配列。JSON以外は出力しない（コードフェンス ``` も付けない・生JSONのみ）。
