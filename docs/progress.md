# デッキ探索システムの開発経過

更新：2026年09月08日 21:14（日本時間）

試行の一覧・詳しい報告・工程の時刻は [探索の記録](http://127.0.0.1:8765/) で読めます。一覧の試行名をクリックすると、手法、検証手順、結果、採否と理由を表示します。

**まだ完成していません。独自で、そこそこ戦えるデッキにつながる案を生み出せるかを、実際の探索で検証しています。**

主役カードを指定せず、案を提出し、別担当の指摘から追加調査・改訂を行う最初の試行を終えました。工程と調査の発展は確認できましたが、**試す理由のある種は残せず、有用性は不合格**でした。この方式の本採用は保留にしています。

今回は、元の構築から6枚を入れ替え、山札で強化したカードをまとめて引く案を材料にしました。特定の局面では利益がある一方、少数の入れ替えでも再現できる部分があり、序盤の補充や攻撃役を減らす負担に見合う根拠を示せませんでした。提案担当は6枚の配分を止め、別評価は補充の着想自体に調査の余地を残しています。全ての使い方を不可能と判断したわけではありません。

固定した5項目の採点は、工程・発展・誠実な説明が合格、正しさは未確認、有用性は不合格です。正しさを合格にしなかったのは、訂正が追加資料に分かれ、提案本文に古い誤りが残っていることと、序盤から必要な状態へ進めるかが未確認であるためです。提出数だけでは追加調査の長さを区切れない点も分かりました。

同じカード資料で「一案を選んで掘る方法」と「複数の着想を短く比較してから選ぶ方法」の比較も終えました。両方式とも有用性は不合格で、短い比較を必須で加える方式の本採用を見送りました。全6検討回・全6別評価で、工程・指定条件の手順・判断の発展・誠実な説明は範囲付き合格でした。手順の合格は訂正資料まで合わせた範囲で、正式案の本文だけが訂正済みという意味ではありません。

一案側は通常の案との差が小さく、準備と失う守護・除去を埋める用途を示せず停止。比較側は防御で稼いだ一手の後の継続と、ヒエンを減らす損失を比較しきれませんでした。比較側の提案担当は停止、別評価は追加検討の余地ありで、推薦には至っていません。この違いを残し、第4回は開始していません。

参考デッキの取得、回答形式の説明、各評価が参照した資料の表示を修正済みです。記録画面を本体へ取り込んだ検査は197件合格しました。検査合格を探索の有用性と混同しません。

検証を知識として蓄積する一覧・詳細画面は、本体へ取り込み、上のURLで稼働しています。15件を登録し、既存12件の説明文も平易な日本語へ編集しました。実際の結果と工程時刻を更新でき、旧版では当時の内容と経過時間が残ります。記録していなかった過去の時刻は「未記録」として扱います。省略文にマウスを重ねて全文を読む機能も本体に取り込み、ユーザーが開いていた一覧画面で表示・クリック・閉じる操作を確認しました。

カードの副作用から別用途を考える補助も試作しました。保存済みの分析を本文と一緒に読ませ、同じ3状況を原文だけの場合と比べました。両方とも条件を正しく区別し、次の検索へ進みましたが、分析追加による改善は確認できませんでした。資料追加に見合う利益が見えないため、今回の本体取り込みは見送りました。実装の関連32件合格と、方式の採用判断は分けて記録しています。
