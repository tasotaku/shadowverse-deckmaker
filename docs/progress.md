# デッキ探索システムの開発経過

更新：2026年9月8日 18:52（日本時間）

**まだ完成していません。独自で、そこそこ戦えるデッキにつながる案を生み出せるかを、実際の探索で検証しています。**

今回は、元の構築の6枚を入れ替え、山札で強化したカードをまとめて引く案を材料に、探索手順を試しています。

今回できたことは、次の3点です。

- 主役カードを指定せずに案を考え、別担当の指摘を受けて比較を追加し、修正案を出すところまで、実際にシステムを使って進めました。
- 追加比較で「入れ替える利点がない」という早い停止判断を見直せました。特定の局面と引き順ではまとめて引く案が勝ち切り、別の引き順では元の構築が先に勝ち切ることが分かりました。
- 参考デッキの取得漏れ、回答形式の説明不足、各評価が参照した資料の分かりにくさを修正しました。最新のコード検査は178件合格です。

**まだ足りないのは、ユーザーが試す理由のある案を残すことです。** 今の案では、必要な局面にどれだけ到達できるか、6枚を入れ替える負担に見合うかが未確認です。指定条件で成立しただけで、強い案として採用してはいません。

現在は、修正案を新しい別担当が評価しています。並行して、同じカード資料を使い、「一案を選んで掘る方法」と「複数の着想を短く比較してから選ぶ方法」を比べる試験を、別々の担当で開始しました。後者がよい方法だとは、まだ判断していません。
