# 独自デッキを見つけるために、探索のどこを変えるか

2026-09-06。過去のナーフとマゼルテンポエルフを材料にした設計検討。新方式の採用案であり、実装済み・発見力を実証済みという報告ではない。

**推奨は、カードの条件を埋める検索を道具として残し、その上に「カードの役割とデッキの組み方を考え直す工程」を置くこと。** 相性のよい2枚を見つけて終わらず、その組み合わせが成立した場合に、何を抜けるか、何を増やせるか、次にどんな問題が生まれるかまで追う。

目指す成果は、知られた早出し手順の再発見ではなく、**ユーザーが試したくなる独自の構築理由**である。マゼルテンポエルフのように、本人の評価でTier3〜4程度でも上位と戦う余地がある構築を含む。運営の意図は外部から確定しにくく、想定外かどうかを採否の必須判定にはしない。

検討したい判断は、この「構築と次の問いを更新する工程」を小規模に試す価値があるか。以下はその判断材料である。

## 1. 五つの事例から取り出せる、四つの発見の仕方

「正常の侵食とエミル」の事例は、説明内容が一致する**壮美なる明越花によるオーディンOTKウィッチ**として整理した。会話中の「おくよバナ」との呼称の対応は確認中。なお、公開記事にも「明越花の転変」という表記があるが、変身効果とナーフ対象を公式で照合すると「壮美なる明越花」である。

| 事例 | 見つける必要があったこと | 探索で必要な工程 |
|---|---|---|
| 明越花OTK | フォロワーを引くことが、山札の変身先を絞る操作にもなる | 効果の別の結果を読み、初期構築と途中の山札を一緒に変える |
| ミルティオ | ゴースト1枚の打点を、集め方・他の打点・使用ターンまで含めた勝ち方へ育てる | 複数の打点源を、実行可能な一つの手順として組む |
| ビバティー | 普通の使い方でも、既存の強い基盤へ小さい負担で入れば十分に強い | 単体の最高値より、採用した構築と採用しない構築を比較する |
| ササニド | 極端な進化回数を作らなくても、デッキ全体の通常の動きが勝ちへつながる | 基盤の行動・余るPP・複数の役割を同時に果たす価値を見る |
| マゼルテンポエルフ | 補充と後半を任せられるため、最初の構築を序盤へ寄せられる | カードの役割を読み替え、前半・切替・後半をつなぐ |

この分類は発見方法の分類であり、「運営が見落とした原因」を特定したものではない。ビバティー・ササニドを通常用途の調整ミスとする評価、マゼルのTierと初見での強さは、ユーザーの見立て・体験として扱う。

### 明越花：サーチで引く札と、山札に残す札を同時に設計する

過去の使用者記事には、正常の侵食でエミルとバーゼントを取り出し、低コスト展開をオーディンへ変える手順がある。正常の侵食の当時の能力はウィッチ・フォロワー2枚のサーチであり、ニュートラルのオーディンを山札に残す役割も果たす。[当時の構築解説](https://note.com/dataerr0r/n/n1f84059ff963)

ここから抽出できる発想の連鎖は、次のようになる。

1. ランダム変身の当たりを増やしたい。
2. 当たりを大量に入れる以外に、外れを先に全部引く方法がある。
3. ウィッチのフォロワーを少数に絞れば、クラス限定サーチがその操作になる。
4. 引く外れ側をエミルのような安く展開できる札にすれば、変身前の体も確保できる。
5. 残る枠を準備・除去・補充へ回し、決着まで到達できる構築を考える。

**三段の応用とは、単に三枚を組み合わせることではない。** 「引く→山札から特定の候補が消える→ランダムを制御できる」という、次の問いの作り替えである。エミルを単体の強さや知名度で先に落とすと、この道が切れる。

一方、変身先を全て手札へ引いてしまう、エミルを引くのが遅く軽減が足りない、展開と変身を同じターンに払えない、といった条件も同じ案の中で扱う必要がある。最大打点だけを発見しても構築は完成しない。

これは過去能力での分析である。明越花は2026-02-27に5→7PPへ変更され、正常の侵食も後に通常の2ドローへ変わった。現在の組み合わせとして再提案するものではない。[明越花の公式変更告知](https://shadowverse-wb.com/ja/news/detail/?id=01KJEEGGM6JWS3G0NNKMJ4DQNE)

### ミルティオ：「3点になる」から、相手を倒す手順へ進む

手札からプレイするゴーストが進化して3打点になると分かっても、それだけでは採用理由が閉じない。「そのターンまでに何枚集まるか」「他の打点へ何PP残るか」「事前に何点削るか」「守護・回復にどう対処するか」へ発展させる必要がある。

ここで計算するのは、**同じ手札・同じPP・同じ場で実行できる打点の合計**。カードごとの最高値を足す方法では、同じ進化権やPPを二度使ってしまう。クレスト取得後はファンファーレ・エンハンスが働かないため、ゴーストを手札に用意する時期や生成方法も手順に含める。場へ直接出るだけのゴーストを、プレイによる進化と混同しない。

RAGEの環境解説は、ゴーストと直接打点の併用、序盤の攻めからOTKまでの複数の勝ち方を説明している。一方、公式のデッキ紹介にもバットによる回復と「残虐の炸裂」による攻めはある。したがって、ユーザーの「バット回復は想定していたのでは」という見立てには対応する記述があるが、ゴーストを含む到達打点を運営が見落としたかは確認できない。現ページの記述だけで、その内容が公開当初から同じだったとも断定しない。[RAGE解説](https://rage-esports.jp/shadowversewb/2026/season1/news/005/)、[公式デッキ紹介](https://collaboration.shadowverse-wb.com/frieren/ja/deck_shindan/result04/)

設計上の教訓は、単体の相乗効果を見つけた後に、**残りの体力を削るための新しい問いを起こすこと**。満タンから20点を出す形だけでなく、前半の削りを後半へつなぐ形も残す。

### ビバティー・ササニド：強い基盤の中で、何を追加できるかを見る

この二例を、必ず複雑な想定外コンボへ分類する必要はない。ユーザーの指摘は、普通に強い基盤があれば、単体では極端でない出力も勝ちに寄与するというものだ。

必要なのは「このカードは何点まで出せるか」に加えて、例えば次の比較である。

- これを入れるために、弱い準備札や使いにくいコスト帯を増やす必要があるか。
- 元のデッキが普通に行う進化・墓場作りなどで条件が満たされるか。
- 攻め・除去・回復・補充のうち、複数の仕事を一枚で持てるか。
- 核を引かなかった試合でも、元のデッキとして戦えるか。
- 同じ枠へ普通の強いカードを入れた場合に比べ、何が改善し、何が悪化するか。

**基盤が強いだけで、小細工まで強いとは限らない。** 採用前後の違いが説明できなければ、既存の強いデッキに不要なカードを混ぜただけの可能性が残る。逆に「普通の効果だから探索前に除外」すると、この型の改善を拾えない。

微妙な数値の強さや環境との相性は、本文の理論だけでは決めにくい。ここは対戦経験や実戦の記録を評価へ戻す必要がある。ナーフされた事実を、そのまま未知のカードの強さを採点する規則へ変換しない。

変更内容からも、見るべき違いが分かる。ビバティーは3→4PPとなり、効果の種類が同じでも他の行動と一緒に使う余裕が変わった。ササニドは進化時のリーダー1点を残し、相手の場全体への1点を失った。後者は顔への理論最大値だけでは捉えにくい弱体化である。**一つの行動で攻めと処理が進むこと、同じターンにもう一枚使えること**を比較する必要がある、というのが本稿の推論だ。変更が勝率へ何点寄与したかまでは、この履歴から決まらない。[ビバティーの公式告知](https://shadowverse-wb.com/ja/news/detail/?id=01KR2RPBYTG315224M1QX4SDQK)、[ササニドの変更前後の照合](https://gamewith.jp/shadowverse-wb/546208)

### マゼル：出力を増やす代わりに、元の構築が負う仕事を減らす

マゼルベインは山札を置換し、ターン終了時に手札を入れ替えて6枚引く。元の構築から後半の札を引けなくなる一方、前半に作った相手の残り体力や消費済みの権利は巻き戻らない。[公式カード本文](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10304110)

発見の流れはこうなる。

**補充源として見る → 後半の手札切れを任せる → 元の構築の後半札を減らす → 序盤を厚くする → 切替ターンの弱さを埋める。**

当時の使用者記事にも、補充を使って攻め続ける解釈と、切替時にベイルを合わせる工夫がある。別の使用者記事も、序盤に手札を使い切ってからマゼルへ移る構築を説明している。これは「補充札を見つけた」で終わらず、配分変更が生んだ次の問題を解く例である。[テンポマゼルベインE](https://note.com/joyous_daisy708/n/n25de106119aa)、[マゼルベインの基本と勝ち方](https://note.com/honakiriko/n/na30a3ae76fcc)

マゼルの6枚補充を7枚や8枚へ増やしてはいない。**固定された出力でも、任せる役割を変えることで構築が変わる。** 最高値の伸びしろだけを入口にすると、この価値を見落とす。

ただし、マゼルを引けない場合、切替時に押し返される場合、置換先で対応しづらい相手には弱点が残る。「必ず相手の除去を使わせる」「前のフォロワーが必ず残る」とは数えない。

## 2. 今の仕組みが持つものと、足りないもの

今の設計にも、効果に伴う別の変化、構築制約、複数枚で条件を満たす方法、デッキの不足から相方を探す方針はある。実際に保存された明越花の要求にも、変身元と山札の当たりの確保が登録されている。したがって「アンカー方式は一段しか考えられない」と断定するのは正確ではない。[現在の設計 §4.5・§6](../design.md)

不足の有力な仮説は、**見つけた結果を使って、次に問うことと仮の構築を更新する運用**である。全実行経路を監査して原因を確定したわけではない。

| 現在の制約・記録 | そのまま適用すると失うもの | 変更案 |
|---|---|---|
| 単体の最高値と条件の難しさで入口を選ぶ | 固定出力の補充や、普通に強い基盤の役割分担 | 別用途とデッキ側の困りごとも入口にする |
| 登録した要求を満たす相方を探す | 検索結果から生まれる別の問い | 結果ごとに「何が可能になり、次に何が不足したか」を作る |
| 核3〜4枚で条件を閉じる | 序盤札の比率、サーチ対象の枚数、抜ける後半札 | 核に加え、採用枚数と役割ごとの構築枠を仮置きする |
| マゼルの旧メモ「元デッキを引けない＝任意カードとのコンボ構築は不可」 | 切替前に使い切る札と、構築配分の協力 | 禁止を「置換後に元デッキから相方を引く前提」に限定する |
| 確定コンボで盤面生存を仮定しない基準 | 攻めを継続する構築の評価まで消す危険 | 確定打点には含めず、全処理・一部残存を分けて検討する |

マゼルのメモは、ゲーム上の事実と、その事実から広く言いすぎた結論を分離する必要がある具体例だった。以前の記録は保持したまま、今回のユーザー評価を追記した。

実際の直近の失敗は、二枚看板＋ミロク＋ヒエンで後攻4〜5ターン目に早出しできると検算し、そのまま優先候補へ上げたことだった。既存の「用意された早出しだけでは想定内」という評価を解消していない。提案方式なら、検算の次に「普通の使い方と何が変わり、構築にどんな利点が出るか」を問い直す。この案はその答えを示せず、発見成果から外れる。[今回の棄却記録](2026-09-06-rethink.md)

また、今の設計ではデッキ全体の最高値を単純合算する探索は、条件への依存が大きく有効でなかったと記録されている。今回の提案はその集計を再開するものではない。**一つの手順で同時に使える値**と、**その手順に寄せた場合のデッキの負担**を分けて扱う。[既存の検討結果 §6.5](../design.md)

## 3. 推奨するシステムの動き

最初から大きな自動探索機を作るより、既存DBと検索を使い、以下の思考を保存・更新できる運用を試すのがよい。

### 入口は三つ持ち、後の工程を共通にする

1. **カードの別用途から入る。** サーチを山札の調整、山札置換を後半の担当、軽減札を安い変身元として読む。効果だけでなく生成物・クレスト・ユーザーメモも読む。
2. **勝つために足りない動きから入る。** 打点、継続して攻める手札、切替時の防御など。「あと何ができれば、どう勝てるか」を具体化する。
3. **強い基盤や惜しい構築から入る。** 何が強さを支え、どこで負けるかを調べる。後半を別の札へ任せる場合などは、既存構築への一枚差しで止めず配分まで変える。

高い出力を狙うカードからの探索は1・2の一部として残る。全てのカードに同じ重さで全用途を列挙させる必要はない。新カード、新しい作用、未解決の負担など、検討する理由がある入口から始める。

### 各案は、次の五項目を更新しながら育てる

| 残す項目 | マゼル型での例 |
|---|---|
| この使い方で何が可能になるか | 手札を使い切っても、後半に補充を続けられる |
| そのために構築をどう変えるか | 序盤札を増やし、元の構築の後半札を減らす |
| 序盤・切替・決着の動き | 序盤に攻め、手札が細る前後でマゼルへ移る |
| 一番大きな未解決点 | 切替ターンに場を取り返される |
| 次に調べる一問と結果 | 切替と同時に安く場を作れる札はあるか。候補を得たら手順を再計算する |

検索は「次に調べる一問」を解くために使う。答えが出たら相方一覧を返すだけで終わらず、上の五項目を更新する。途中で主役や勝ち方が変わってもよい。

更新と検索はAIが担当し、同じ案の記録へ根拠と棄却理由を追記する。ユーザーには途中の検索操作を任せず、試す価値がある構築と、判断を変える不明点を渡す。保存先は既存の調査記録を使えばよく、新しいDBや専用画面を先に作る必要はない。

枝を続けるのは、具体的な役割変更、必要PPの減少、要求枚数の減少、成立する分岐の追加など、新しい根拠が増えたとき。問いも証拠も変わらないまま札を足す反復は止める。未解決案は不足条件を残し、新弾などで条件が変わった際の再検討につなぐ。

### 判定は、何を確かめたかを分ける

- **成立するか**：当時または現在の対象フォーマット、カード本文、生成物、順序、PP、手札・場の上限、進化権。確定事項は機械で検算し、未実装の効果は本文に戻る。
- **構築として無理がないか**：必要札の枚数、引く手段、準備中の行動、核を引けない場合、抜いたカードの損失。完成40枚を固定しなくても、核の枚数と残りの役割別の枠数は示す。
- **普通の構築より何がよいか**：核を抜いた近い構築、または一般的な相方へ置き換えた構築を一つ比較対象にする。最大値だけでなく、必要な準備と負け方の違いを書く。
- **独自の使い方か**：カードの同居だけでなく、役割、配分、使用順、勝ち方を既存構築と比較する。検索で未発見というだけでは新規性を保証しない。

引ける確率を算出する場合は採用枚数・引き直し・サーチ条件を固定する。役割別の枠数だけの段階で精密な確率を装わない。これらの検査を通っても、勝率や環境上の強さを証明したことにはならない。

### 最後にユーザーへ渡すものを変える

核カードと「噛み合う理由」に加え、次を一枚の案として渡す。

**どう役割を変えたか／何を増減した構築か／通常の動き／引けない場合の動き／比較対象との差／最大の弱点／既出状況。**

初見での強さを狙うなら、「何を相手が読み違え、どの判断が変わるか」まで具体化する。独自性を一律の強さの加点にしない。実戦では、初めて見る相手と構築を知った相手への結果を分けて記録する。知られた後の強さを調べることは、初見の価値を失格にする条件ではない。

## 4. この案を本採用する前に確かめること

過去の成功例をうまく説明できることと、未知のデッキを発見できることは違う。ナーフ例だけで学ぶと、大打点や壊れたカードばかり探し、マゼルのような目標をまた落とす。今回のヒエン案のような「成立するが求める成果ではない案」も比較に置く。

まずは今回の五例を使い、必要な発想が途中で落ちないかを確認する。過去の能力とカードプールを固定し、ナーフ後の本文や未来のカードを混ぜない。完成レシピを見せなくてもAIが既知知識を持つ可能性があるため、これは工程の穴を探す確認であり、新規発見能力の証明にはしない。

次に、同じカード範囲・同じ調査時間・同じ情報源で、現在の方法と提案方法を比べる。見せる案の数もそろえ、方法名を伏せてユーザーが評価できる形がよい。見るのは、

- 試したい独自の構築理由が出たか。
- 成立手順と、核を引けない場合まで説明できたか。
- 既知の普通の用法や、過去に却下された理由の再提示が減ったか。
- ユーザーが誤解や計算を直す負担が減ったか。

である。調べた枚数・検算した件数・ナーフを再現した件数を成功の代用にしない。まず小さく運用し、本当に何段目で止まるかを見てから、必要な部分を実装することを推奨する。

一回分の試行案は、対象を一つの新カード群または構築上の課題へ絞り、各方法30分・最終提示は最大3案とする。数値は比較を揃えるための仮の予算で、効果を保証する基準ではない。「新方式だけで試したい案が出るか」を最初の判断材料にし、同じ差が別の対象でも出るかを次に確かめる。結果が同じ、または訂正の負担が増えるなら、工程を増やしただけで本採用しない。これは試行の提案であり、今回すでに比較したという意味ではない。

## 5. 確認範囲と未確定事項

対象はユーザーが挙げた五事例＝明越花・ミルティオ・ビバティー・ササニド・マゼルテンポエルフ。ナーフ履歴全件の網羅調査ではない。変更履歴の出典と取得できた範囲は[証拠メモ](2026-09-06-discovery-design-evidence.md)に分けた。

公式の変更内容、使用者による公開解説、ユーザーの評価、本稿の設計推論を区別した。ユーザーが使ったマゼルの正確な40枚と対戦記録、各カードについての運営の内部認識、提案方式の発見率は未確認。既存設計・DBを調べて述べた制約は、プログラム全体の実行を監査した結果ではない。
