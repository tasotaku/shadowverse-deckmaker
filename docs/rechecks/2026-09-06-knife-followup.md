# 潜伏ナイフの追加検討：ベルゼバブを残す形で比較する

**現在の評価は低優先の参考案。強い案としての採用は勧めない。** ベルゼバブ2枚・リオナ2枚の構築と条件付きの成立手順は作れたが、枠や進化権を費やして早い決着を追加する価値を示せていない。対戦で弱さを実証した結論ではなく、現時点の検討材料からの判断である。新しい探索方法の本採用も引き続き保留する。

当初は比較用の試作候補として残した。ユーザーの「それ強いのか？」という問いを受け、成立手順・負担の説明が揃ったことと、優先して試す価値があることを分けて再評価した。ユーザー自身が弱いと断定したという記録ではない。

21点のうち11点が、前のターンに置いたナイフとリオナの攻撃。特にリオナ自身には潜伏がなく、その5点を安定した決着手段として見込む根拠がない。リオナを失うと、同じ札・通常進化の2体手順は16点になる。これはリオナが倒される頻度の測定ではなく、1体の除去で決着が崩れることの確認。

追加ヨグを使う3体手順ではリオナ生存を要求せず、旧ナイフが残れば条件付き20点以上の分岐がある。したがって、リオナの除去だけを理由に案全体を不成立とはしない。ただし、こちらは追加のヨグを揃える必要があり、旧ナイフの生存・人形の当て先・攻撃通過の条件も残る。従来のベルゼバブ型は、ナイフ本体を前ターンから残す必要なく能力だけで20点を作れる。1ターン早める機会がこれらの負担に勝ることは、今回示せていない。

前回の[比較試行](2026-09-06-method-trial.md)で保留した案を追加検討した記録。前回の入力・採点・候補数は変更しない。今回の発展を、前回の探索が発見した成果に遡って加算しない。

## 何を入れ替えるか

比較元を、[Game8の9月5日更新の公開40枚](https://game8.jp/shadowverse-beyond/813914)に固定した。これは比較のための選択で、最良の構築という認定ではない。3通りの全カードと枚数は[比較リスト](2026-09-06-knife-followup/decks.json)に保存した。

| カード | 公開構築 | 全て抜く案 | 残す案 |
|---|---:|---:|---:|
| ベルゼバブ | 3 | 0 | 2 |
| マリオネットランサー | 1 | 1 | 0 |
| リオナ | 0 | 3 | 2 |
| その他の共通カード | 36 | 36 | 36 |

2枚ずつは最適な配分という結論ではない。従来の決着を複数枚残し、交換を2枠に留めて効果を見るための開始案とした。1枚・3枚を残す配分との比較は行っていない。

ルリアは比較元から0枚。コスト7以上を引く能力なので、6コストのナイフを探す札にはならない。前回の「ルリアも減らす」という曖昧な枠の説明は、この追加検討では使わない。

全て抜くと、ベルゼバブの「2体の能力を失わせて各9ダメージ」「9/9の本体」「本体が除去されても残る打点増加」を全て失う。潜伏ナイフが除去された場合やリオナを引けない場合に、従来の決着へ戻る道もなくなる。兵器・製図・アイズエデンの処理は残るが、同じ働きを代替できるとは言えない。

残す案も無料ではない。ベルゼバブが1枚減って従来の決着を引きにくくなり、ランサーの2/1本体と手札の改良人形1枚を失う。リオナは2/2守護として置けるが、改良人形による処理の代わりにはならない。採用2枚のリオナから1枚を引く条件と、潜伏付与へ超進化1回を残す負担も増える。双方の決着を欲張って中途半端になる可能性は対戦で未確認。

## 追加のヨグを引けない時にも分岐がある

前回は「潜伏ナイフを次のターンに3体へ増やす」を中心に考えた。追加検討では、**ナイフ2体でも21点になる条件**を確認した。

準備は共通。シアターから0PP人形3枚を保存し、玩具のアクセラレート2＋ヨグ2などで深淵を取得する。8PPでナイフ6→深淵0で3PPのナイフを手札へ→リオナ2を超進化して元のナイフを潜伏させる。潜伏を付けた後は、そのターン中に追加の人形を出さない。ナイフの能力ダメージで潜伏が解けるため。

次のターン、元のナイフと超進化リオナが生存し、両方の攻撃が顔に通るなら、次の計算になる。

- 元のナイフを通常進化して攻撃：6点。
- リオナの攻撃：5点。
- 保存したナイフを3PPで出す。出てくる人形2体：ナイフ2体の能力で4点。
- 保存した0PP人形3枚：同じく6点。**計21点**。

相手の場が小鬼3/3だけの場合に、具体的に成立する。場に出た通常人形と保存人形の最初の2枚を順に当てて倒し、最後の人形は出すだけでよい。改良人形は場に残してよい。追加のヨグと3体目のナイフは不要になるが、通常進化1回とリオナの生存が新たに必要。

共通枠に3枚入っている**誠心なる尽小花**を1PPで使う分岐もある。相手の守護が1体だけなら小鬼3/3へ変身させ、守護を外しながら当て先を用意できる。対象にできる相手アミュレットも当て先に変えられる。決着日の支払いは保存ナイフ3＋変身1＝4PP。対象にできないカード、別の守護が残る盤面、相手の場が完全に空の場合は、この説明だけでは解決しない。

リオナが倒されている場合はこの21点に使えない。前回の「追加ヨグ＋ナイフ3体」の分岐ならリオナの攻撃を必要としないが、追加札と別の場の計算が要る。どちらの分岐も、潜伏ナイフの生存と人形の当て先が条件となる。

## 試す時に何を比較するか

提示した手順では、潜伏型は後攻7ターン目に追加PPを使って準備し、8ターン目の決着を狙える。先攻は8→9ターン目。ベルゼバブを先に置く[公開手順](https://note.com/shiden_noise/n/n8f19bdb3629f)の後攻8→9・先攻9→10より1ターン早い。これは必要札が揃った手順の比較で、実戦の平均決着ターンではない。

| 状況 | 残す案で選べること／残る問題 |
|---|---|
| リオナがない、超進化を使い切った | ベルゼバブから従来の決着を狙う。ただし採用2枚へ減った影響がある。 |
| ベルゼバブがない、潜伏の準備が揃った | 早い決着を狙う。相手の除去で潜伏ナイフを失う危険がある。 |
| 追加のヨグがない | リオナも残り、通常進化と当て先を確保できれば、2体の21点分岐がある。 |
| ナイフがない | 両方の決着が止まる。イマリや兵器などで盤面を作りつつ探すが、別の確定した勝ち筋とは評価しない。 |
| 相手の場が完全に空 | 人形で場を空ける説明が成立しない。変身札でも当て先を作れない。 |

実戦で見るべきなのは「潜伏によって間に合った試合」と「ベルゼバブやランサーを減らして失った試合」。潜伏する前に除去された、という分類ではなく、潜伏を準備できたか、準備後にナイフが残ったか、最後の当て先と攻撃が確保できたかまで記録する。今回は対戦しておらず、いずれも件数・勝率は未測定。

## 探し方について分かったこと

**「1枚足りない時にどう勝つか」「抜く札の働きは誰が担うか」を具体的な構築へ問い直すこと**で、2体と既存の変身札を使う分岐までは作れた。しかし、追加ヨグの要求を外した代わりに、リオナ生存と通常進化を要求している。条件を別の条件へ交換しただけでも、分岐が増えたという理由で成果に数えてしまう評価の甘さがあった。

この1件は、役割・構築・勝ち方を行き来して考え直す方法の具体例にはなる。ただし、カードの条件から相方を探す従来法でも同じ発展ができる可能性はある。未知の別候補で繰り返して結果を比較しない限り、新方式の発見力が上だとは言えない。

カード本文は当日の公式照合済みデータに基づく。枚数・ローテ合法性・新弾採用と、指定盤面からの計算を確認した。独立確認の結果は[検証記録](2026-09-06-knife-followup/review.md)を参照。実戦での成立頻度、初見での対処の難しさ、ユーザーが試したいと思うかは未確認。
