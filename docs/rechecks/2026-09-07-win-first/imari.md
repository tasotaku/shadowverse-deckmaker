# 潜伏イマリ：スペル17枚へ寄せる構築は優先候補から外す

2026-09-07のAIによる再評価。ユーザーがこの案を直接見送ったという記録ではない。前回の凍結結果は変更しない。

**判断：提示済みのスペル17枚型を、優先して試す候補から外す。** 潜伏の役割変更は成立するが、勝ち札を減らしてまでこの処理能力へ寄せる理由を示せていない。

採る理由は、イマリが残れば補充・回復スペルに小鬼を添え、以降のターンも処理と手札維持を両立できること。単なる一回の除去とは異なる継続性があり、リオナや小鬼が残らなくても成立する点はナイフ2体21点案より堅い。

採らない理由は、カット3枚に加え、イマリとリオナ各1枚を揃え、超進化1回を使うため、仕組みの始動は後攻6／先攻7以降となること。それに合わせてスペルを比較元9枚から17枚へ増やし、通常の勝ち札を減らしている。始動前に弱い札を引く負担は先払いで、得られる処理能力は始動後。ニューロン各1枚のPP回復は毎ターンではない。前回例は6枚取得でも、使用・破棄を差し引いた手札の純増は1枚で、確定リーダーダメージは0。盤面の残存による攻めはあり得るが、相手の処理を越えて勝ちへつながることは未確認。

現行ハイランダーの使用者記事には、カットを探すために序盤札を手放すと殴り切られる問題と、ナイトメアやフェイスドラゴンの厳しさがある。この案はその始動前の弱さを直接改善しない。別の使用者は繰り返す強い展開への対応と安定性を課題にしており、継続処理がそこに役立つ仮説はある。ただし既存の除去・回復札より有効という比較を作れていないため、強い理由としてはまだ足りない。記事は個人の使用感で、全体勝率の根拠ではない。

最も強い反論：小鬼で処理を続ければ既存の疾走札を顔へ回せるため、直接打点0だけでは弱いと断定できない。その可能性は残す。ただし今回は、それを理由に17枚の配分や各1枚の取得難を正当化しない。普通の構築へリオナ1枚を加える小さな変更まで否定する評価ではないが、それを独自のデッキ発見として提出もしない。
