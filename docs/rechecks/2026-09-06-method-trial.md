# 探索方法を実カードで比べた結果

2026-09-06。**提案した方法の方がよい、という結果にはまだなっていない。本採用は保留する。** 同じ113枚を使い、従来法と提案法を別の担当で試した。従来法から潜伏イマリの試作候補が出た。提案法で最も進んだ潜伏ナイフは、担当が取り下げた後、独立確認では構築上の発展があると評価されたが、構築の損失が未整理で保留になった。

この記録は、本プロジェクトのユーザーが探し方の採用と候補の試行価値を判断するためのもの。今回試したのはカード調査の方法で、ゲーム内での対戦、勝率、必要札を揃えられる頻度は測っていない。「ユーザーが試したいと思う案を出せたか」の評価も未回答であり、AIの検査で代行しない。

| 比較 | 従来法：登録した要求から探す | 提案法：役割と構築を更新して探す |
|---|---|---|
| 調べ方の例 | 「リオナで守る価値がある相手は何か」から、相方と不足する条件を探す | 「ベルゼバブを省いて早く勝てるか」から、使い方・採用配分・残る弱点を更新する |
| 調査時間 | 25分48秒 | 15分18秒 |
| 具体的に検討した仮説 | 13件 | 7件 |
| 担当が最後に提出した候補 | 1件：潜伏イマリ | 0件。独立確認後、ナイフ1案を保留として保存 |
| 最も進んだ案 | イマリを継続的な小鬼の供給元にし、ニューロンへつなぐ | ナイフを前ターンに潜伏させ、次ターンに3体へ増やしてベルゼバブを省く |

両方とも上限30分とし、具体的な問いが尽きた場合は早く終了できる条件だった。実際には10分30秒の差がある。対象も各方法の担当も一組だけなので、候補数から従来法の方が優秀だとも結論しない。仮説数は作業範囲の記録であり、発見の質を表す点数ではない。

**潜伏イマリで出た構築理由。** カットスロートのクレストでイマリを自動進化させると、同じターンにリオナへ超進化権を使ってイマリを隠せる。イマリ自身は小鬼を出すだけなので、小鬼が攻撃してもイマリの潜伏は解除されない、という公式本文からの読みである。補充・回復・除去スペルを、毎ターン3/3突進も得られる札に変える。小鬼を並べたあとにニューロンでPPを戻し、次のスペルへつなぐ。[公式イマリと小鬼](https://shadowverse-wb.com/web/CardList/card?card_id=10574120&lang=ja)、[公式リオナ](https://shadowverse-wb.com/web/CardList/card?card_id=10871120&lang=ja)、[公式カットスロート](https://shadowverse-wb.com/web/CardList/card?card_id=10974110&lang=ja)

例えば、後攻T6にイマリ2PP＋リオナ2PPで準備。T7に潜伏イマリだけが残り、指定札が揃っていれば、放逐1→照臨1→ニューロン5・PP3回復→穢れなき日々3を7PPで行える。小鬼3体、進化ニューロン、潜伏イマリの5枠へ収まり、補充と2回復までつながる。これは上振れの手順例であり、毎試合の動きではない。ほかの味方が残る場合は生成数を減らす必要がある。

核はカットスロート3枚、イマリ・リオナ・ニューロン各1枚。試作配分はフォロワー21・スペル17・アミュレット2。比較元の公開ハイランダーは28・9・3で、通常のカット＋イマリは既出である。今回の差は、保護して使い続けるためにスペルを増やす点。最大の弱点は各1枚の核を揃える難しさと、フォロワーを減らした構築が通常の試合でも戦えるかが未検証なこと。イマリが引けなければ、通常の重複なし構築として処理と疾走で戦う想定を置いた。[比較元の公開構築](https://gamewith.jp/shadowverse-wb/573928)、[候補の手順・配分・弱点](2026-09-06-method-trial/anchor-result.md)

独立確認でも、イマリ案は試作候補として残す判定だった。核がない場合の動きと、勝ち札を減らして弱いスペルを引く損失まで説明できているためで、損失を実戦で埋められたという判定ではない。継続するのはイマリの小鬼生成であり、PP回復はニューロンを使ったターンだけ。上の手順の取得6枚に対し、使用・破棄を引いた手札の純増は1枚である。[独立確認](2026-09-06-method-trial/blind-review-c1.md)

**潜伏ナイフは、見送り理由まで再検査した。** ナイフとリオナの組み合わせは8月27日の記録にあり、両担当とも最初はその具体化へ進んだ。提案法では、準備日に3PPのナイフを手札へ作り、翌日にヨグゼンタと合わせて3体を8PPで並べる手順まで進んだ。ベルゼバブを置くターンを省く構築変更であり、独立確認では「既知のペアというだけで落とすべきではない」と評価された。

ただし、ベルゼバブとルリアを減らして失う除去・補充・勝ち方と、リオナ3枚・超進化権・追加の準備の交換条件は整理できていない。20点の例も、ナイフの生存、ヨグと人形を倒せる相手の当て先、守護を処理してナイフの攻撃を通すことが条件。試作候補へ昇格させず、保留案として残す。[凍結した案](2026-09-06-method-trial/blind-candidate-c2.md)、[独立確認](2026-09-06-method-trial/blind-review-c2.md)

**この試行から直せるのは、方法の呼び名より判定の仕方。** 従来法でも「潜伏の受け手→同時に進化する方法→小鬼からPP→スペル配分」という複数段の発展が起きた。一方、提案法は役割と構築を更新していても、最後に「既登録の具体化」として発展した案まで取り下げた。良さそうな相方を発見する工程と、残すか決める工程は分けて観察する必要がある。

次の比較では、既知の組み合わせに近い案ほど、**何を減らせたか・何を早められたか・代わりに何を失うか**を同じ表へ書いてから見送るのがよい。これは今回の観察からの改善仮説であり、発見率が上がることを確認した変更ではない。大きな探索実装の置き換えは行っていない。

事前条件は[試行条件](2026-09-06-method-trial-protocol.md)として結果より先に保存した。同じモデル設定、同じ入力、各30分まで・提出最大3案。途中で主担当が伝えたのは、カミシラの古い備考の誤りと、潜伏ナイフが以前の記録へ登録済みという共通事実で、相手の途中案は渡していない。方法を伏せた独立確認は2案＝試作候補として残す1＋保留1。主担当も本文・手順・比較元を確認した。
