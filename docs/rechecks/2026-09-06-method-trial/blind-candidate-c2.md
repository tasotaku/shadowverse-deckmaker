# 候補 C2：潜伏ナイフをコピーし、ベルゼバブの前置きを省く

ローテーションのネメシス＋ニュートラル。手順と構築理由の評価用で、方法名・作成者の採否は伏せる。採点対象は以下の凍結内容。独立確認で新しい候補へ作り替えない。

核の仮配分はナイフ3・リオナ3・ヨグ3・ドールズシアター3。深淵の事前取得に低劣の玩具または愚劣の兵器、残りは補充と除去を使う想定。ベルゼバブとその取得のためのルリアを減らす構築変更まで考えたが、完成40枚は作っていない。

- シアター1枚から0PP人形3枚を保存。別ターンに玩具のアクセラレート2＋ヨグ2で深淵を用意する。玩具の3枚ドローは発動しない。
- 後攻T7は追加PP込み8PPでナイフ6→深淵0で3PPナイフを保存→リオナ2を超進化して最初のナイフへ潜伏。先攻は同じ手順をT8に行える。
- 次ターンにヨグ2→保存ナイフ3→ヨグの新しい深淵からナイフ3で計8PP。相手へ人形を当てて場を空け、手札の0PP人形3枚を追加する。
- リオナが残る場合、三体目のナイフの人形は場5枠のため1体しか出ない。人形の能力ダメージは4＋3＋9＝16。旧ナイフの攻撃4点を通せば20点。直前ターンの2点は含めていない。
- 原本ナイフを引くのは1枚で足りる。切替開始時の必要手札7枚、余剰1枚を含む8枚から始める例で上限9を超えない。SEPはリオナへ1回。

**この20点は固定の出力ではない。** 人形やヨグを倒せる相手の当て先、潜伏ナイフの生存、旧ナイフの攻撃を通せる守護処理が必要。他の味方の残存で場が狭くなる場合も再計算が必要。ナイフを引けない場合は除去と補充で探すしかなく、この核だけの代替の勝ち方は閉じていない。

相手が進化前クラトス7/7を置き、こちらに旧ナイフと超進化リオナが残った状態なら、人形とヨグで第一のクラトスを処理し、二体目をリオナで倒して、能力16＋リオナの破壊時1＋旧ナイフ4＝21点となる具体計算をログに残した。対戦で再現した結果ではない。
