# ナイトメア・ドラゴンの再考（2026-09-06）

## 今回残すもの

独立した新しい勝利手段はまだ閉じていない。ただし、前回の「有望0件」で打ち切ると落ちていた、**大佐の結晶を先に置き、6ターン目の除去・補充・進化権温存へ変える枝**を具体化できた。まず検討するのは案1と2。どちらもセレスの墓場20達成を前提にせず動く。強さ・勝率を実戦で確認したものではない。

ナイトメア106枚、ドラゴン106枚、ニュートラル69枚の非トークン計281枚と、生成物26枚を原文・ユーザーメモ込みで再読。ローテ180枚に加え、アンリミ限定101枚も含む。既存の7案は再掲せず、以下の6案を比較した。

## 1. 大佐の結晶 → 渇命の破壊者：超進化を使わず中盤を返す

**ローテーション。今回の比較候補。**

- 淵底の大佐 `10952110`：本体6PP・4/6守護。破壊時に敵フォロワー1体をランダム破壊、リーダー2回復。結晶2PP・カウント4で本体を出す。
- 渇命の破壊者 `10653110`：5PP・3/3。味方1体を破壊して自動進化。自身が進化したときバットを出し、バットも進化。
- 双方に、この組み合わせを否定するユーザー固有メモはない。セレス・アルメス・魂の捕食・渇仰の悪魔のメモは読み、単なる展開を守りと呼ばない基準を適用した。

### 手順と得

T2に大佐を結晶2PPで置く。カウントはT3開始3、T4開始2、T5開始1、T6開始0となり、T6の行動前に4/6守護の大佐が出る。これは普通のフォロワーが4ターン生存する仮定ではない。

T6に渇命の破壊者5PPで大佐を破壊する。大佐の破壊時能力で敵1体をランダム破壊し、2回復。破壊者に自傷はない。5/5の進化破壊者と3/3の進化バットを得る。両方ともそのターンに敵フォロワーへ攻撃でき、**EP・SEPを一切消費せず進化回数が2増える**。バットが3点の戦闘ダメージを与えられれば追加3回復。敵が大佐の能力で全滅した場合は攻撃先がないため、3回復は保証しない。

当該ターンの5PPに対して「敵1体破壊＋2回復＋即時攻撃できる5/5と3/3ドレイン」、残り1PP。渇命自身を普通に進化する使い方と違い、準備した大佐の破壊時能力が別の除去と回復を担う。準備込みは2枚・7PP。

### 比較上の意味

- イステンデッドや徒姫でSEPを使って守る案に対し、SEPをアルメスへ残せる中盤の選択肢。
- 渇仰の悪魔＋魂の捕食のように、2/2を失って自傷しながらドローする案ではない。大佐を失う代わりに敵を破壊し、2回復し、即時に働く2体へ変換する。
- ただしドローは0枚。墓場も結晶と大佐の計2だけがこの時点で増え、破壊者・バットの将来の破壊を先取りして数えない。**補充と墓場20を単独で解決しない。**
- 大佐が本体になった後には守護があるため、相手の攻撃を止めたい場面では破壊しない選択もある。
- 大佐が出る前のT2〜T5は守りにならない。結晶を引けない試合や、消滅・変身された試合はこの線が成立しない。

### 反復・追加の分岐

T3に2枚目の結晶を置けばT7にも同じ5PPの動きを用意できる。T6に出した通常のフォロワーが生き残る前提は不要。2回なら準備4PP＋使用10PP、4枚消費、進化4回。ただし補充は依然0。

T6後攻のエクストラPP、またはT7以降の7PPが使えるなら、大佐に死神払い2PP→渇命5PP。敵1体破壊、2回復、自動進化2体に加え、大佐4/6守護も新品で残せる。準備大佐を含め3枚・合計9PP、当該ターン7PP、盤面3枠。これは進化権なしで守護を維持する枝であり、毎ターン無限に繰り返せる意味ではない。

### 既出状況

検索 `"淵底の大佐" "渇命の破壊者"` と `"大佐" "渇命" ビヨンド` では同じ手順の明確な掲載を確認できなかった。未発見・世界初の証明ではない。渇命で破壊時効果を利用すること自体は既存の仕組みで、新しい勝利手段とは区別する。

## 2. 大佐の結晶 → 死神払い → 魂の捕食：守護を維持して補充する

**ローテーション。案1と同じ大佐を、手札が足りないときに使う枝。**

追加カードは死神払い `10953310` 2PP、魂の捕食 `10052310` 2PP。死神払いは同名を場へ出す能力を与える。引き継がれるのは同名の印刷された能力で、付与した死神払いそのものは引き継がれない。

T2の結晶からT6に大佐が出たら、死神払い2PP→魂の捕食2PPで破壊する。**当該ターン4PPで、2ドロー・敵1体のランダム破壊・2回復、新品の4/6守護が残る。EP・SEPは不要。** 残り2PPは除去等へ使える。

普通の渇仰の悪魔＋捕食との比較では、自分の守護を新品で残し、自傷せず回復し、敵1体を除去する。代わりに死神払い1枚・2PPと結晶を待つ時間を追加で払う。この追加費用を無視して「捕食が強くなった」とは言わない。

手札は当該ターン2枚使って2枚引くため純増0。T2の大佐まで含め3枚使って2枚引くので、コンボ全体では1枚減る。ただし除去と回復を行うターンにも山札を2枚進められ、守りへ手札を使って補充が止まる問題を緩和する。墓場は結晶1＋大佐本体1＋スペル2で、この時点の計4。残した大佐が後に破壊されたとき、追加の敵1体破壊・2回復・墓場1を得るが、これは将来の条件付き出力として分ける。

### 反復の実際

T2/T3/T4にそれぞれ結晶を置くと、T6/T7/T8に毎回新品の大佐が出る。各ターンに死神払い＋捕食を使えば、毎回4PPで上記の出力を繰り返せる。古い大佐の生存は不要。3回分は準備6PP＋起動12PP、9枚使用・6枚ドロー、最大3枚の守護を順番に供給。確定の墓場は12、残した3体も破壊されれば計15。

これは**上限3回の資源を払う反復**。3枚の死神払いを使い切るとアルメス用を残せず、しかもT2〜T4に計6PPを予約に使う。実用比較では1〜2回を道中に使い、残りをアルメスへ回す方を先に検討する。セレス達成やコンボ成功率向上が確定した、とはまだ言えない。

### 何が既知か

大佐＋死神払いは[新弾の個人レビュー](https://www.nyantan-kkkmhf.com/?p=3344)に同じ維持の説明がある。そのため中心ペアを新発見として扱わない。検索で見つかった[個人構築報告](https://note.com/mizugoro0489/n/n0ae27c25ace2)は死神払いの主対象を中尉としており、大佐＋捕食の反復を一般的な定着として証明するものでもない。

今回残す比較点は、**大佐を結晶で予約することで、4PPの除去・回復・補充へ落とし、アルメス向けの超進化を温存する役割**。大佐単独の採用枚数や実戦性能は未検証。

## 3. ルインジェノサイダー → ゲテンオウ → バトラー：10PP札の支払い不足を埋める

**ローテーション。成立する補助だが、ランダムな出力を制御できず継続検討止まり。**

ルインジェノサイダー `10543110` 7PP・SEPで山札の奇数コストを消滅、八界花・ゲテンオウ `10504110` 8PPで2枚引き-8。ドラゴニュートバトラー `10942120` は元8PPなので0PPでプレイでき、3PP回復を行う。その3PPで、同時に引いたイランツァ `10544110` の10→2PPを払える。

例えば8PP開始でゲテンオウ→残り0。引いたバトラー0→残り3、イランツァ2→残り1。イランツァを進化させれば終了時8点、進化させなければ敵2体への8点と8回復。バトラーの3回復も別に得る。新バトラーがなければ、8PP開始で引いたイランツァ2PPをそのターンに出せない。

ただし、これは山札に2種類だけが残る保証ではない。ゲテンオウ自身が偶数8PPで残る。イランツァ2枚を同時に引くと残りPP不足が残る。奇数デッキ化は自分の序盤のカード選択を縛り、ルイン用SEPも払う。**『どの2枚でも強い』という条件を閉じられていないため、新しい有望種とは判定しない。**

基礎のルイン→ゲテン→イランツァは[既存の奇数ドラゴン](https://gamewith.jp/shadowverse-wb/537720)として定着している。`"ルインジェノサイダー" "ドラゴニュートバトラー"` と `"奇数ドラゴン" "バトラー"` では同一記述は確認できず。ただし新バトラーを差すだけの補強が既存型を変えるほどかは未確認。

## 4. セレス → アンサージュ＋死神払い＋捕食：軽く攻めながら補充する

**ローテーション。成立するが、死神払いによるアンサージュ再攻撃は既出。**

セレス `10854120` の軽減を受けたアンサージュ `10851110` は2PP、死神払いと捕食は各0PP。アンサージュを超進化して守護無視5点→死神払い0→捕食0→新品アンサージュ2点。起動2PPで計7点、2ドロー、最後に2/3が残る。復活体は疾走が印刷されているため、そのまま攻撃可能。スージー等の手札バフや超進化はコピーへ引き継がれない。

セレスの5PP・墓場20・手札に3枚を揃える準備を別払いする。墓場20の難しさを解消せず、アルメス用のSEPも1つ使うため、現在のアルメス構築へそのまま戻す提案ではない。攻めと補充を同時に行う別の軽減先として記録。

[9月4日の動画一覧](https://yutura.net/channel/149519/latest/)に「死神払いで2回攻撃アンサージュ」の動画（同ページ取得時9,134再生）があり、中心の手順を新発見とは呼ばない。セレスを含む詳細は動画本文未確認。

## 5. スージー → メドゥーサ＋ラウラ：18点は出るが既に言及あり

**アンリミテッド。成立、少数既出。**

スージー `10853110` 4PP＋EPで手札のメドゥーサ `10154120` を3→6攻撃へ。後の10PPでメドゥーサ7PP＋ラウラ `10253110` 3PP、ラウラへSEPを使いメドゥーサに疾走を付ける。守護なしなら6×3＝18点。守護1体はメドゥーサの攻撃時破壊で突破できるが、1回攻撃を使うため顔は12点へ落ちる。

3枚・準備4PP・決着10PP・EP1・SEP1。セレスは必須ではないが、軽減がなければ始動T10（後攻エクストラPPならT9）。手札バフと3回攻撃が噛むことは明確だが、この遅さを解消する段階で墓場20の問題が戻る。

[7月のアンリミ事前評価](https://note.com/gifted_minnow310/n/nfa08354fc659)に同じ18点が書かれている。単独記事だけで広く定着とまでは判定しないが、新発見としては提示しない。

## 6. 乙姫の扇・炎竜の剣で、新弾の前ターン攻撃条件を継続する

**アンリミテッド。仕組み成立、既存フェイスドラゴンの範囲。**

乙姫の扇 `10143210` は設置1PP、毎ターン3PPと捨て札1枚で2/2疾走守護。炎竜の剣 `10242210` は設置1PP、1PPアクトでそのフォロワーを+1/+1し、破壊時に剣が戻る能力を与える。前のターンに顔を攻撃しておき、次にアンテマリア `10944110` 等の条件を通す。捨て札をヴォーラライや天刀授与にすれば損失を緩和できる。

ただし扇と剣だけで4PP・毎ターン手札1枚を払い、守護があれば2〜3点を顔へ通せる保証はない。[現行アンリミのフェイスドラゴン](https://gamewith.jp/shadowverse-wb/574589)が扇とヴォーラライ、アンテマリアを既に同じ方針で扱う。扇＋剣も[2025年8月の実況](https://www.nicozon.net/watch/sm45245325)に同じ組み合わせがある。新しい種に数えない。
