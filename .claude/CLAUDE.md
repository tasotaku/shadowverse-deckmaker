# shadowverse-deckmaker プロジェクトルール

## フィードバックの2層記録（常時適用・ユーザー明示指示 2026-07-05）

会話中にユーザーからカードゲームに関する訂正・評価・ルール知識が出たら、その場で必ず以下に振り分けて永続化する（後回しにしない）:

1. **汎用ルール**（フォーマット・判定原則・ゲームルール前提など、カードをまたいで効くもの）
   → `docs/design.md` の該当節に追記してコミット
2. **カード固有の事実**（効果の正しい読み・実戦評価・ローテ落ち・コンボ可否など）
   → DB のユーザレイヤ `card_note` テーブルに card_id 付きで追記（既存noteがあれば ` / ` 区切りで追記。上書きしない）

マッチング・目利きの工程では、アンカー側だけでなく**供給候補側の card_note も参照**して同じ誤判定を繰り返さない。

## 前提ドキュメント

作業開始時は `docs/design.md` を読む（§1.5 フォーマット公理・§5 アンカー基準・§6 マッチング・§7 novelty は毎周使う）。
