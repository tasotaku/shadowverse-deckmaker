# ACG全体設計のために利用者が共有した目的（2026-10-30）

この資料は現在の会話で利用者が明示した内容の記録です。過去の資料やコードからのAI推定ではありません。

根本の目的は「自分の好きなデッキを作る」こと。そのデッキ作りをシステムで支援したい。
デッキ作りには「想定外のコンセプトのデッキを作る」と「既存のデッキを別の形に変える」の二つがある。
分析に使うため、公式からカード情報を取得することも全体の要件に含める。

以下は資料との照合と今回の調査範囲（AIによる整理）：
- 「運営が想定してない」という発想を利用者は挙げた。一方、docs/design.mdでは独自性を「一般に広まっているか」で判断する。両者を同じ判定基準と断定しない。
- システムが40枚デッキを自動完成するとは要求していない。現在の資料では核カードと構築方針までを支援し、40枚化・実戦の判断は人が行う。
- 対戦環境は検証用の別領域としてREADMEに記述されている。全体設計では対戦の操作窓口も確認し、エンジン内部の網羅性や対人での強さは未検証とする。
