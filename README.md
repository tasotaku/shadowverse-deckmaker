# shadowverse-deckmaker

Shadowverse の「想定外デッキ」を探すための実験リポジトリ。

定番の強デッキをなぞるのではなく、**人間が思いつきにくいカードの組み合わせ**を
探索・評価して提案することを目的とする。趣味の個人プロジェクト。

## コンセプト

「想定外」の切り口は複数ありうる。まずはどれかに絞って手を動かす:

- **メタ外し系** — 既存の強デッキ分布から外れた構成を出す（統計・多様性重視）
- **シナジー発見系** — カード効果テキストを解析し、非自明なコンボを見つける（グラフ探索寄り）
- **AI対戦評価系** — 対戦をシミュレートし、勝てる意外なデッキを進化的に探す

## セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt   # 依存が増えたら作成
```

## ステータス

まだ雛形のみ。方針を決めてから `src/` に実装を入れる。
